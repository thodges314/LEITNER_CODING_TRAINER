Implement breadth-first level-order traversals on binary tree nodes shaped `{ val, left, right }`:

### `levelOrder(root: TreeNode<number> | null): number[][]`
- Returns the level order traversal of node values as an array of arrays, grouped by depth level from left to right.
- Returns `[]` if `root` is `null`.

### `rightSideView(root: TreeNode<number> | null): number[]`
- Returns an array of values visible when looking at the tree from the right side (the last node value at each level).
- Returns `[]` if `root` is `null`.

### `zigzagLevelOrder(root: TreeNode<number> | null): number[][]`
- Returns the zigzag level order traversal as an array of arrays, alternating traversal direction between depths.
- Even depths (0, 2, ...) traverse left-to-right; odd depths (1, 3, ...) traverse right-to-left.
- Returns `[]` if `root` is `null`.
