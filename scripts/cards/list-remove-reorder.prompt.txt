List nodes are { val, next } (null ends the list).

Write removeNthFromEnd(head, n): remove the n-th node from the end in one pass (two pointers n apart; n is valid) and return the head.

Write reorderList(head): rearrange in place to L0 -> Ln -> L1 -> Ln-1 -> ... (find the middle, reverse the second half, interleave); it returns nothing.

Write deleteDuplicates(head): in a SORTED list keep one copy of each value and return the head.
