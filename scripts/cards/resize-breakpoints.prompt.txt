Write observeBreakpoint(element, breakpoints, onChange, RO = ResizeObserver) that reports which named width breakpoint an element is in, like a container query done in JavaScript. breakpoints maps a name to its minimum width, for example { sm: 0, md: 600, lg: 1000 }, in any key order. Create one observer with new RO(callback) and observe the element. For each entry the callback receives, read entry.contentRect.width; the active breakpoint is the one with the largest minimum that is not above the width (a width equal to a minimum belongs to that breakpoint), or null when the width is below every minimum. Call onChange(name) for the first measurement and afterwards only when the active breakpoint changes (including a change to null). Return a stop function that disconnects the observer.
