Implement element container queries using `ResizeObserver`:

### `observeBreakpoint(element, breakpoints, onChange, RO = ResizeObserver)`
- Observes the content width of `element` and triggers `onChange(name)` when its matching container breakpoint changes.
- `breakpoints` maps breakpoint names to minimum width thresholds in any key order (e.g. `{ sm: 0, md: 600, lg: 1000 }`).

#### Breakpoint Matching
- Reads `entry.contentRect.width` from the observer entries.
- The active breakpoint is the one with the **largest minimum threshold** that is less than or equal to the element's width (boundary values belong to that breakpoint).
- If the width is below all thresholds, the active breakpoint is `null`.

#### Notification & Lifecycle
- Calls `onChange(name)` on the initial measurement.
- Afterwards, calls `onChange(name)` **only** when the resolved breakpoint changes (including transitions to or from `null`).
- Returns a cleanup function `() => void` that disconnects the observer.
