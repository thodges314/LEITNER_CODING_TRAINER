Build an accessible progress bar supporting determinate and indeterminate states:

### ProgressBar({ value, max = 100, label = 'Progress' }: { value?: number; max?: number; label?: string }): JSX.Element:
- **Root Element**: Render `<div role="progressbar">` with `aria-label={label}`, `aria-valuemin="0"`, and `aria-valuemax={max}`. Let `clamped` be `value` limited to the range `[0, max]`.
- **Determinate State** (when `value` is defined):
  - Set `aria-valuenow` to `clamped` on the root.
  - Render `<div data-fill style={{ width: ((clamped / max) * 100) + '%' }} />` inside it (the exact percentage, e.g. `"50%"` or `"75%"`).
  - Render `<span>{Math.round((clamped / max) * 100)}%</span>` inside it (a whole number followed by `"%"`).
- **Indeterminate State** (when `value` is `undefined`):
  - Set `data-indeterminate="true"` on the root element.
  - Omit `aria-valuenow`.
  - Render `<div data-fill />` with no inline style at all.
  - Do **NOT** render the `<span>` (no percentage text).
