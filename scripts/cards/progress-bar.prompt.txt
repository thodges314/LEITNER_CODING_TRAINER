Build ProgressBar({ value, max = 100, label = "Progress" }). Render <div role="progressbar"> with aria-label={label}, aria-valuemin="0", aria-valuemax={max} and aria-valuenow set to value clamped into [0, max]. Inside it render a fill element <div data-fill> whose style width is the exact percentage clamped/max*100 (e.g. "50%", "75%") and a <span> showing that percentage rounded to a whole number followed by "%". When value is undefined the bar is indeterminate: omit aria-valuenow, set data-indeterminate="true" and render no percentage text.
