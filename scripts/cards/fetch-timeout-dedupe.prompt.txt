Implement request deduplication with timeout abortion:

### `dedupeFetch(key, fn, timeoutMs = 5000)`
- `fn(signal)` is a factory function that returns a Promise for the asynchronous request.

#### Deduplication Behavior
- Concurrent invocations sharing the same `key` return the identical in-flight `Promise`.
- The entry is removed from the cache in a `.finally()` handler once the request settles (on success, rejection, or timeout) so subsequent calls trigger a fresh fetch.

#### Timeout & Cancellation
- If the operation does not settle within `timeoutMs`:
  - Triggers abortion via the `AbortSignal` passed to `fn(signal)`.
  - Rejects the returned promise with an `Error` (e.g. `Timed out after ${timeoutMs}ms`).
- Clears the pending timeout timer when the request finishes before the deadline.
