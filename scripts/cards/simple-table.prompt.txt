```ts
interface Column<T> {
  key: keyof T & string;
  label: string;
}
```

Build a simple table component:

### SimpleTable<T extends Record<string, unknown>>({ columns, rows }: { columns: Column<T>[]; rows: T[] }): JSX.Element:
- `columns` is an array of column descriptor objects (`Column<T>[]`, e.g. `[{ key: 'name', label: 'Name' }, { key: 'age', label: 'Age' }]`).
- `rows` is an array of row data objects (`T[]`, e.g. `[{ name: 'Ada', age: 36 }, { name: 'Grace', age: 45 }]`), where each object represents a table row mapping column keys to cell values.
- Render a `<table>` with a `<thead>` row of `<th>` cells showing each column `label`.
- Render a `<tbody>` with one `<tr>` per row and one `<td>` per column in `columns` order showing `String(row[column.key])` (or an empty string `''` for missing, `undefined`, or `null` values).
- When `rows` is empty, render a single `<tr>` with one `<td colSpan={columns.length}>` reading `'No rows'`.
