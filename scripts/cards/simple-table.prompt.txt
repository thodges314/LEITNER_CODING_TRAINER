Build SimpleTable({ columns, rows }) where columns is [{ key, label }] and rows is an array of objects. Render a <table> with a <thead> row of <th> cells showing each label, and a <tbody> with one <tr> per row and one <td> per column showing String(row[column.key]) (an empty string for a missing/undefined/null value). When rows is empty render a single <tr> with one <td colSpan={columns.length}> reading 'No rows'.
