### SearchForm(props: { onSearch: (query: string) => void }): JSX.Element
Build a controlled search form component in React:

- Renders a `<form>` containing a controlled `<input>` and a `<button type="submit">Search</button>`.
- **Controlled State**:
  - Maintains `query` state via `useState('')`.
  - Links `<input value={query} onChange={(e) => setQuery(e.target.value)} />`.
- **Form Submission**:
  - Handles `<form onSubmit={handleSubmit}>`.
  - Calls `event.preventDefault()`.
  - Trims the input value: `const trimmed = query.trim()`.
  - Calls `onSearch(trimmed)` only if `trimmed` is not empty.
  - A blank or whitespace-only query must **not** invoke `onSearch`.
