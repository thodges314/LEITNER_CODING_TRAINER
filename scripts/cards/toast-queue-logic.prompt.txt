A toast (notification) system keeps an array of toasts like { id, message, expiresAt? }. Write the pure functions that update it; none of them changes the array it is given.

addToast(toasts, toast, max = 3): add toast at the end. When a toast with the same id is already in the list, update that toast in place (merge the new fields, keep its position) and add nothing. When the list would end up with more than max toasts, drop the oldest ones (from the start) so that max remain.
dismissToast(toasts, id): the list without the toast that has that id (an unknown id changes nothing).
expireToasts(toasts, now): remove every toast whose expiresAt is at or before now. A toast without expiresAt never expires.
