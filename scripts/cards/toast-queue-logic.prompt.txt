Implement pure state helper functions to manage a toast notification queue (`{ id, message, expiresAt? }`) without mutating input arrays:

### `addToast(toasts, toast, max = 3)`
- If a toast with the same `id` already exists:
  - Updates that toast in-place by merging new fields while preserving its queue position.
- Otherwise:
  - Appends `toast` to the end of the queue.
  - If the resulting length exceeds `max`, drops the oldest toasts from the front so at most `max` items remain.
- Returns the new queue array.

### `dismissToast(toasts, id)`
- Returns a new array excluding the toast with the given `id`.
- If `id` is not found, returns the queue unchanged.

### `expireToasts(toasts, now)`
- Returns a new array removing every toast whose `expiresAt <= now`.
- Toasts without an `expiresAt` property never expire.
