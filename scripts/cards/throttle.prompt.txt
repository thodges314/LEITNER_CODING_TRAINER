Implement throttle(fn, wait, { leading = true, trailing = true } = {}) so fn runs at most once per wait window. leading: true runs the first call immediately; leading: false waits for the end of the window. trailing: true fires the last call made during a window at the window's end with its latest arguments; trailing: false drops calls made during the window. With leading: false the first call is delivered at the end of its window.
