Tree nodes have the structure `{ id: string, label: string, children?: TreeNode[] }`.

Write tree flattening and expansion utilities for virtualized tree rendering:

### `flattenVisible(nodes, expandedIds)`
- Flattens hierarchical tree nodes into an ordered array of visible row objects (depth-first traversal, parent before children, siblings in order).
- `expandedIds` is a `Set` containing IDs of currently expanded nodes.
- Each row is `{ id, label, depth, hasChildren, expanded }`:
  - `depth`: integer starting at `0` for root nodes and incrementing with each nesting level.
  - `hasChildren`: `true` only if `Array.isArray(node.children) && node.children.length > 0`.
  - `expanded`: `true` only if `hasChildren` is true and `expandedIds.has(node.id)`.
- Children are visited and included only when their immediate parent is `expanded`. A collapsed parent hides its entire subtree (even if a nested descendant's ID is in `expandedIds`).

### `toggleExpanded(expandedIds, id)`
- Immutably toggles membership of `id` in `expandedIds`.
- Returns a **new `Set`** with `id` added if previously missing, or deleted if previously present.
- Does not mutate the input `expandedIds` set.
