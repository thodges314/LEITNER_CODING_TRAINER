Write canPartition(nums): true when the positive integers can be split into two subsets with equal sum (an empty array is true).

Write findTargetSumWays(nums, target): the number of ways to put a + or - sign in front of every number so the total equals target (reduce it to a subset-sum count; [0, 0, 0] with target 0 has 8 ways; 0 when impossible).
