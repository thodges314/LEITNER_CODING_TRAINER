Implement generator workflows and an asynchronous coroutine runner:

### `function* createEchoGenerator(): Generator<'ready' | [unknown, string], void, unknown>`
- Generator function that initially yields `'ready'`.
- On subsequent steps, receives an input passed via `it.next(val)` and yields `[val, typeof val]`.

### `runCoroutine<T = unknown>(generatorFn: (...args: any[]) => Generator<any, T, any>, ...args: any[]): Promise<T>`
- Coroutine runner (mini `co`) executing `generatorFn(...args)`.
- For each yielded value:
  - Can be a `Promise` or plain value; awaits its resolution.
  - Passes the resolved value back into the generator via `it.next(resolvedValue)`.
  - If a promise rejects, passes the error into the generator via `it.throw(err)`.
- Returns a `Promise` that resolves to the generator's final return value (when `done: true`), or rejects if an unhandled error is thrown.
