Write function* createEchoGenerator(): a generator function that first yields 'ready'. On subsequent iterations, it receives an input via it.next(val) and yields [val, typeof val]. Write runCoroutine(generatorFn, ...args): a runner (mini 'co') that calls generatorFn(...args) to get an iterator. Each yielded value can be a Promise or plain value; the runner awaits it, passes the result back via it.next(resolvedValue). If a yielded promise rejects, it passes the error into the generator via it.throw(err). Returns a Promise resolving to the generator's final return value.
