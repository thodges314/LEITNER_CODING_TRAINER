Implement a Least Recently Used (LRU) cache class operating in O(1) time complexity for all operations:

### `new LRUCache<K = number, V = number>(capacity: number): LRUCache<K, V>`

- **`get(key)`**:
  - Returns the cached value associated with `key`.
  - Returns `-1` if `key` does not exist in the cache.
  - Marks `key` as the most recently used entry.
- **`put(key, value)`**:
  - Inserts or updates the entry for `key` and marks it as most recently used.
  - If adding a new key causes the cache to exceed `capacity`, evicts the least recently used key.
