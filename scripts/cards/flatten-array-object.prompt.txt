Implement recursive flattening utilities for arrays and nested objects without mutating inputs:

### `flatten<T>(arr: unknown[], depth: number = Infinity): T[]`
- Recursively flattens nested arrays up to the specified `depth`.
- If `depth` is omitted or `Infinity`, flattens nested arrays completely.
- Preserves non-array elements as-is.

### `flattenObject(obj: Record<string, unknown>, prefix: string = ''): Record<string, unknown>`
- Recursively flattens nested plain objects into dot-separated paths (e.g., `{ a: { b: 1 } }` -> `{ 'a.b': 1 }`).
- Only expands non-empty plain objects.
- Leaves arrays, `Date` instances, `null`, empty objects `{}` and primitives as leaf values.
