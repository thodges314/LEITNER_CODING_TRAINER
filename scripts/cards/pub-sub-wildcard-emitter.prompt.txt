Write `class PubSub` supporting pattern-based event emission:

### `new PubSub(): PubSub`

- **`subscribe(pattern, handler)`**:
  - Registers `handler` for `pattern` and returns an unsubscribe function `() => void`.
  - Patterns support exact names (e.g. `'user.login'`) or wildcards:
    - `'user.*'` matches any `'user.<word>'`.
    - `'*'` matches every topic.
- **`publish(topic, data)`**:
  - Calls all matching subscriber handlers with arguments `(data, topic)`.
  - Returns the total count of listeners invoked.
- **`once(pattern, handler)`**: Registers a listener that executes only once for the first matching publication and automatically unsubscribes.
- **`clear()`**: Removes all active subscriptions across all topics.
