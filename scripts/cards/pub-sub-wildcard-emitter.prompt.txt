Write class PubSub with methods: subscribe(pattern, handler) registers a callback and returns an unsubscribe function () => void. Patterns can be exact (e.g. 'user.login') or wildcard (e.g. 'user.*' matches any 'user.<word>', or '*' matches everything). publish(topic, data) calls matching listeners with (data, topic) and returns the count of listeners invoked. once(pattern, handler) registers a handler that runs only the first time a matching event is published, then automatically unsubscribes. clear() removes all subscriptions.
