Write createThermometer(celsius) returning an object with an enumerable data property `celsius` and a NON-enumerable accessor property `fahrenheit` defined with Object.defineProperty: its getter returns celsius * 9 / 5 + 32 and its setter takes a Fahrenheit number and updates celsius to (f - 32) * 5 / 9 (so JSON.stringify of the object only shows celsius).

Write defineLazy(obj, key, compute): defines an enumerable, configurable getter that calls compute() on the first read, then REPLACES itself with a plain data property holding that value (writable, enumerable, configurable) so compute never runs again; returns obj.
