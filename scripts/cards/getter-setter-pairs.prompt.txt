### `createThermometer(celsius: number): { celsius: number; fahrenheit: number }`
- Returns an object with an enumerable data property `celsius` and a **non-enumerable** accessor property `fahrenheit` defined with `Object.defineProperty`.
- Its getter returns `celsius * 9 / 5 + 32` and its setter takes a Fahrenheit number and updates `celsius` to `(f - 32) * 5 / 9` (so `JSON.stringify` of the object only shows `celsius`).

### `defineLazy<T extends object>(obj: T, key: string | symbol, compute: () => any): T`
- Defines an enumerable, configurable getter that calls `compute()` on the first read, then **replaces itself** with a plain data property holding that value (`writable: true`, `enumerable: true`, `configurable: true`) so `compute` never runs again.
- Returns `obj`.
