Implement a Node.js callback-to-promise adapter:

### `promisify(fn: (...args: any[]) => void): (...args: any[]) => Promise<any>`
- Converts a Node-style callback function (where the last argument is a callback `(err: any, result?: any) => void`) into a function returning a `Promise`.
- The returned promise resolves with `result`, or rejects with `err` when `err` is truthy.
- Forwards all arguments, preserves `this` context, and rejects if `fn` throws synchronously.
