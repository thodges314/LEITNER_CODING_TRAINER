Write rateLimiter({ limit, windowMs, now = Date.now }) returning middleware (req, res, next) that allows each client (req.ip) up to `limit` requests per `windowMs` using a token bucket. When a client is out of tokens, do NOT call next(): set res.statusCode = 429, set a Retry-After header (whole seconds until a token is available) with res.setHeader, and call res.end(). Evict buckets that have been idle longer than windowMs so memory does not grow, and expose middleware.size() returning the number of tracked clients.
