Write `rateLimiter({ limit, windowMs, now = Date.now })` returning an Express-style middleware `(req, res, next)`:

- **Token Bucket per Client**: Allows each client (`req.ip`) up to `limit` requests per `windowMs` using a token bucket.
- **Rate Limit Exceeded**: When a client has no available tokens:
  - Do **NOT** call `next()`.
  - Set `res.statusCode = 429`.
  - Set a `Retry-After` header using `res.setHeader` (rounded up to whole seconds until the next token refills).
  - Call `res.end()`.
- **Memory Eviction**: Evict client buckets that have remained idle for longer than `windowMs` to prevent memory leaks.
- **Client Count**: Expose `middleware.size()` returning the count of currently tracked clients.
