Write rafThrottle(fn, raf, caf) that limits fn to one call per animation frame, as used for scroll and pointermove handlers. raf and caf default to the browser's requestAnimationFrame and cancelAnimationFrame and can be replaced in tests. The returned function remembers its latest arguments; the first call in a frame schedules one frame with raf, further calls before that frame only replace the arguments. When the frame runs, call fn once with the latest arguments, and allow a new frame to be scheduled afterwards (also from inside fn). The returned function has a cancel() method that cancels a pending frame with caf (and does nothing, without calling caf, when nothing is pending).
