Without using native `Promise.all`, implement an array concurrency combinator:

### `myAll<T>(items: (T | Promise<T>)[]): Promise<T[]>`
- Takes an array `items` of values and/or promises.
- Returns a `Promise` resolving to an array of results in the **exact same index order** as `items` (not order of completion).
- **Completion Tracking**:
  - Uses a remaining counter to track how many items have resolved.
  - Resolves when all items have finished.
- **Immediate Rejection**:
  - Rejects as soon as any item's promise rejects (with that rejection reason).
- **Edge Case**:
  - `myAll([])` resolves immediately to `[]`.
