Build a lightweight observable state store:

### createStore<T extends Record<string, unknown>>(initialState: T): Store<T>
- Returns `{ getState, setState, subscribe }`.

#### Store Methods
- **`getState()`**:
  - Returns the current state object.
- **`setState(partial)`**:
  - Replaces state with a **new object** shallow-merging the current state with `partial` (`{ ...state, ...partial }`).
  - Never mutates the existing state object directly.
  - Calls every registered listener passing the new state, in the exact order they subscribed.
- **`subscribe(listener)`**:
  - Registers `listener` and returns an `unsubscribe` function.
  - Listeners are **not** invoked upon subscription, only on subsequent `setState` calls.
  - Once unsubscribed, that listener is never invoked again.
