Build a lightweight browser client-side router integrated with the HTML5 History API:

### `createRouter(routes, win = window)`
- `routes` is an ordered list of route definitions: `[{ name: 'user', path: '/users/:id' }, ...]`.
- Starts at `win.location.pathname` and listens to `win` for `'popstate'` events.

#### Pattern Matching & Resolution
- Segments starting with `':'` capture named parameters (decoded via `decodeURIComponent`).
- Static segments must match identically.
- Empty segments (leading, trailing, and double slashes) are ignored.
- The segment count must match, and the first matching route in the list wins.
- A path with no match resolves to `{ name: null, params: {}, path }`.

#### Router Methods
- **`current()`**: Returns the current resolved route `{ name, params, path }`.
- **`navigate(path)`**:
  - Does nothing if `path` equals `current().path`.
  - Otherwise calls `win.history.pushState(null, '', path)`, resolves the new route, and notifies subscribers.
- **`replace(path)`**:
  - Calls `win.history.replaceState(null, '', path)`, updates the route, and notifies subscribers.
- **`subscribe(fn)`**:
  - Subscribes `fn(route)` to change events (not called immediately upon subscription).
  - Returns an unsubscribe function.
- **`destroy()`**:
  - Cleans up by removing the `'popstate'` listener from `win` and clearing all subscribers.
