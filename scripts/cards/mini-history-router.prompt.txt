Write createRouter(routes, win = window), a tiny client-side router built on the History API. routes is an ordered list like [{ name: 'user', path: '/users/:id' }]; a segment starting with ':' captures a parameter (decoded with decodeURIComponent), every other segment must match exactly, the number of segments must be equal, empty segments (leading, trailing and double slashes) are ignored, and the first matching route wins. A path with no match resolves to name: null. A route object is { name, params, path } where path is the path as given. The router starts from win.location.pathname and listens for 'popstate' on win (browser back/forward) by resolving win.location.pathname again. It returns { current(), navigate(path), replace(path), subscribe(fn), destroy() }. navigate(path) does nothing when path equals the current route's path; otherwise it calls win.history.pushState(null, '', path), updates the route and notifies subscribers. replace(path) is the same with win.history.replaceState and always applies. subscribe(fn) calls fn(route) on every change (not immediately) and returns an unsubscribe function. destroy() removes the popstate listener and all subscribers.
