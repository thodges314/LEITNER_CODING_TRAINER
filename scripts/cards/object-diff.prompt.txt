Write diff(a, b) that compares two plain objects and returns the list of differences between them. Each change is one of exactly these shapes, with no other properties: { path, type: 'added', to } for a key that only exists in b, { path, type: 'removed', from } for a key that only exists in a, and { path, type: 'changed', from, to } for a key whose value differs. path is the dot-joined key path ('user.address.city'). Two plain objects at the same key are compared recursively, and a nested key reports its full path; a whole subtree that is only in one object is reported once, at the key where it starts. Every other value pair is compared as a whole: primitives with Object.is (so NaN equals NaN, and a key holding undefined still counts as present), arrays element by element and deeply (an array change is reported once, at the array's own path), Dates by their time. A value that is an object on one side and not on the other (a primitive, null or an array) is a 'changed'. Order: first the keys of a in their order (removed and changed ones), then the keys that are only in b ('added') in their order. Equal objects give [].
