Implement structural object diffing producing path-level change records:

### `diff(a, b)`
- Recursively compares plain objects `a` and `b` and returns an array of change records:
  - `{ path, type: 'added', to }` — key exists in `b` but not `a`.
  - `{ path, type: 'removed', from }` — key exists in `a` but not `b`.
  - `{ path, type: 'changed', from, to }` — value changed between `a` and `b`.
- **Path & Nesting Rules**:
  - `path` uses dot-separated property notation (e.g., `'user.address.city'`).
  - Only plain objects are recursively traversed; identical sub-objects produce no change records.
  - Arrays and `Date` instances are treated as atomic leaf values (arrays compared by element equality, `Date` compared by `.getTime()`).
