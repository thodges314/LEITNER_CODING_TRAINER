### `Button({ variant = 'primary', disabled = false, children, ...props }: ButtonProps): JSX.Element`

## Description

```ts
type ButtonVariant = 'primary' | 'outline';

interface ButtonProps {
  variant?: ButtonVariant;
  disabled?: boolean;
  children?: any;
  onClick?: (event: any) => void;
  [key: string]: any;
}
```

Build an accessible, versatile button component styled with Tailwind CSS utility classes:

### Requirements
- **Container (`<button>`)**:
  - Element: `<button type="button" ...>` (defaults to `type="button"` unless specified in `props`).
  - Layout & interactive base utilities: inline-flex centered alignment, medium font weight, rounded corners, horizontal and vertical padding, small text sizing, color transition, `focus-visible` outline removal with a focus ring, active press scale-down, and pointer cursor.
  - Forwards extra props (such as `onClick`, `data-testid`, or `aria-label`) to the underlying `<button>`.
- **Variants**:
  - `'primary'` (default): solid blue background with white text, darker blue hover state, and blue `focus-visible` ring.
  - `'outline'`: bordered button with neutral gray border and text, subtle light-gray hover background, and gray `focus-visible` ring.
- **Disabled State**:
  - When `disabled` is `true`:
    - Sets HTML attribute `disabled={true}` on the `<button>`.
    - Includes Tailwind disabled utilities for reduced opacity, disabled pointer events, and a not-allowed cursor.

### Example Usage
```tsx
<Button variant="primary" onClick={() => console.log('clicked')}>
  Save Changes
</Button>
<Button variant="outline" disabled={true}>
  Cancel
</Button>
```
