Write function overloads and exhaustive checking utilities:
- Function formatInput:
  overload 1: formatInput(value: string, toUpper: boolean): string
  overload 2: formatInput(value: number, precision: number): string
  implementation: formats a string to uppercase if toUpper is true (lowercase if false); formats a number with toFixed(precision).
- function assertNever(x: never, message?: string): never: throws an Error(message || `Unexpected value: ${x}`). In switch statements, assigning an unhandled branch to assertNever ensures exhaustiveness at compile time.
- function isTagged<T extends { tag: string }, K extends string>(item: T, tag: K): item is Extract<T, { tag: K }>: type guard narrowing a discriminated union item by tag.
