Write function overloads and exhaustive checking utilities:

### `formatInput` (Overloaded)
- `formatInput(value: string, toUpper: boolean): string`
  - Formats string to uppercase if `toUpper` is `true`, lowercase if `false`.
- `formatInput(value: number, precision: number): string`
  - Formats number with `toFixed(precision)`.

### `assertNever(x: never, message?: string): never`
- Throws an `Error(message || \`Unexpected value: \${x}\`)`.
- In `switch` statements, assigning an unhandled branch to `assertNever` ensures exhaustiveness at compile time.

### `isTagged<T extends { tag: string }, K extends string>(item: T, tag: K): item is Extract<T, { tag: K }>`
- Custom type guard narrowing a discriminated union `item` by its `tag` property.
