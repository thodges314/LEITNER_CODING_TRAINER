Implement compound components Tabs({ defaultValue, value, onChange, children }), TabList, Tab({ value }) and TabPanel({ value }) sharing state via context. Tabs is uncontrolled with defaultValue, or controlled when `value` is passed (calling onChange(next) on clicks). Only the selected panel is rendered. ARIA: TabList role='tablist'; Tab is a button role='tab' with aria-selected and aria-controls = its panel id; TabPanel role='tabpanel' with id and aria-labelledby = its tab id. ArrowRight/ArrowLeft move focus between tabs (wrapping) with roving tabindex.
