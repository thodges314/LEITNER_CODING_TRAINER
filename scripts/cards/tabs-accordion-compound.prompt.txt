```ts
interface TabsProps {
  defaultValue?: string;
  value?: string;
  onChange?: (value: string) => void;
  children?: React.ReactNode;
}

interface TabListProps {
  children?: React.ReactNode;
}

interface TabProps {
  value: string;
  children?: React.ReactNode;
}

interface TabPanelProps {
  value: string;
  children?: React.ReactNode;
}
```

Implement compound components sharing state via context:

### Tabs({ defaultValue, value, onChange, children }: TabsProps): JSX.Element
- `TabList({ children }: TabListProps): JSX.Element`: container for tab buttons.
- `Tab({ value, children }: TabProps): JSX.Element`: single tab button.
- `TabPanel({ value, children }: TabPanelProps): JSX.Element | null`: content panel associated with a tab.

**Behavior & Accessibility**:
- `Tabs` is uncontrolled when given `defaultValue`, or controlled when `value` is passed (calling `onChange(next)` on clicks).
- Only the selected panel is rendered.
- **ARIA**: `TabList` has `role="tablist"`. `Tab` is a `<button role="tab">` with `aria-selected` and `aria-controls` matching its panel ID. `TabPanel` has `role="tabpanel"` with `id` and `aria-labelledby` matching its tab ID.
- **Keyboard Navigation**: `ArrowRight` and `ArrowLeft` move focus between tabs (wrapping at boundaries) using roving `tabIndex`.
