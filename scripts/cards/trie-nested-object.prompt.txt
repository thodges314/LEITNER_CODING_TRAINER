Write buildTrie(words) returning a trie made of plain nested objects: one key per character, and the key '$' set to true on the node where a word ends (buildTrie(['a', 'ab']) is { a: { $: true, b: { $: true } } }; no words gives {}). Write hasWord(trie, word) (true only for complete words) and hasPrefix(trie, prefix) (true when some word starts with prefix; the empty prefix is true for any non-empty trie).
