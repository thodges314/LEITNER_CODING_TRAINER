Implement three reference and timer utility hooks: `usePrevious`, `useLatest`, and `useInterval`.

### `usePrevious(value)`
- Returns the value from the previous render (`undefined` on initial mount).

### `useLatest(value)`
- Returns a React `ref` object whose `.current` property is always updated to the latest `value`, allowing effects or callbacks to read the current value without adding it to dependency arrays.

### `useInterval(callback, delay)`
- Invokes the **LATEST** `callback` every `delay` ms.
- Changing `callback` does **NOT** reset the active timer.
- Setting `delay = null` pauses the interval; restoring a numeric delay resumes it.
- Cleans up and clears the timer on unmount.
