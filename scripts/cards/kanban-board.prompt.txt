Build an interactive multi-column Kanban board for tracking tasks across workflow stages.

## Description
```ts
export interface KanbanCard {
  id: string;
  title: string;
  description?: string;
}

export interface KanbanColumn {
  id: string;
  title: string;
  cards: KanbanCard[];
}

export interface KanbanBoardProps {
  initialColumns: KanbanColumn[];
  onCardMove?: (cardId: string, fromColumnId: string, toColumnId: string, newIndex: number) => void;
  onCardAdd?: (columnId: string, card: { title: string; description?: string }) => void;
}
```

### KanbanBoard({ initialColumns, onCardMove, onCardAdd }: KanbanBoardProps): JSX.Element
- **Column Layout**:
  - Renders a container with `data-kanban-board` holding all columns.
  - Each column container has `data-column-id={column.id}`.
  - Each column header renders its title in `data-column-title` and card count in `data-column-count`.
- **Card Rendering**:
  - Each card is rendered within its column list (`data-card-list`) with `data-card-id={card.id}`.
  - Card elements contain `data-card-title` with the card title, and `data-card-description` if `description` is provided.
- **Card Movement Between Columns**:
  - Each card provides a "Move Left" button (`data-action="move-left"`) and a "Move Right" button (`data-action="move-right"`).
  - Move Left is disabled on cards in the first column (`colIndex === 0`).
  - Move Right is disabled on cards in the last column (`colIndex === columns.length - 1`).
  - Clicking "Move Right" shifts the card from the current column to the end of the next adjacent column, and calls `onCardMove(cardId, fromColumnId, toColumnId, newIndex)` with the new index in the target column.
  - Clicking "Move Left" shifts the card from the current column to the end of the previous adjacent column, and calls `onCardMove(cardId, fromColumnId, toColumnId, newIndex)` with the new index in the target column.
- **Card Creation**:
  - Each column includes an "Add Card" trigger button (`data-action="toggle-add-card"`).
  - Clicking toggle reveals a creation form with:
    - Title text input (`data-card-input="title"`).
    - Description textarea (`data-card-input="description"`).
    - Submit button (`data-action="submit-card"`).
    - Cancel button (`data-action="cancel-card"`).
  - Clicking cancel resets form fields and closes the creation form.
  - Submitting with empty/whitespace-only title does nothing.
  - Submitting with valid title appends a new card to the column, resets/closes the form, and calls `onCardAdd(columnId, { title, description })`.

### Optional Styling (CSS is not graded)
Optional helper classes are available in the preview environment:
- `.kanban-board`: horizontal flex row layout with gap and horizontal scrolling.
- `.kanban-column` (or `.kanban-col`): column container with border, background, and spacing.
- `.kanban-card`: task card with border, rounded corners, padding, and background.
- `.kanban-card-actions`: row layout with gap for move buttons.
You may use these classes, custom styles, or your own class names.
