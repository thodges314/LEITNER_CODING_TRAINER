### `AvatarGroup({ avatars = [], max = 4, size = 'md', className = '', ...props }: AvatarGroupProps): JSX.Element`

## Description

```ts
type AvatarSize = 'sm' | 'md' | 'lg';
type AvatarStatus = 'online' | 'offline' | 'busy' | 'away';

interface AvatarData {
  src?: string;
  name: string;
  alt?: string;
  status?: AvatarStatus;
}

interface AvatarProps extends AvatarData {
  size?: AvatarSize;
  className?: string;
  [key: string]: any;
}

interface AvatarGroupProps {
  avatars: AvatarData[];
  max?: number;
  size?: AvatarSize;
  className?: string;
  [key: string]: any;
}
```

Avatar clusters represent collaborative team members, issue assignees, and active participants in compact visual headers.

Build an accessible, responsive `AvatarGroup` component (and supporting `Avatar` sub-component) styled with Tailwind CSS utility classes:

### Requirements

- **Individual** `Avatar` **Component**:
  - Container (`<span>`):
    - Relative, non-shrinking inline-flex centered circle with semibold non-selectable text, a 2px ring for stack separation, and neutral slate/gray background and text.
    - Sizes scale width, height, and font size progressively (`'sm'`, `'md'` default, `'lg'`).
    - Forwards extra `props` (like `data-testid` or `onClick`).
  - Image & Initials Fallback:
    - If `src` is provided and loads without error, renders a full-bleed circular `<img>` (cropped to cover) with `alt={alt || name}`.
    - If `src` is missing or fails to load (`onError`), renders uppercase initials from `name`:
      - Single-word name: first 2 characters (e.g. `'Sarah'` -> `'SA'`).
      - Multi-word name: first letter of the first word and first letter of the last word (e.g. `'Alex Rivera'` -> `'AR'`, `'John Fitzgerald Kennedy'` -> `'JK'`).
  - Status Indicator Dot:
    - When `status` is provided, renders `<span aria-label={status} />` anchored at the bottom-right corner as a circle with a 2px ring, scaled to match `size`.
    - Variant background colors: `'online'` (emerald/green), `'busy'` (rose/red), `'away'` (amber/yellow), `'offline'` (slate/gray).

- `AvatarGroup` **Stack Component**:
  - Container: `<div role="group" aria-label="Team avatars" {...props}>` as a centered inline-flex horizontal stack with negative horizontal spacing so avatars overlap and clipped overflow (plus any external `className`).
  - Overlap & Truncation:
    - If `avatars.length <= max`: renders all avatars in order.
    - If `avatars.length > max`: renders the first `max` avatars, followed by a circular overflow counter pill matching the active `size`, styled with the same 2px ring, neutral surface, hover state, and transition:
      - Displays text `+${avatars.length - max}`.
      - Has attribute ``aria-label={`${avatars.length - max} more team members`}``.
