Write matchRoute(pattern, pathname) and createRouter(routes, initialPath = '/'). matchRoute returns an object of params or null: ':id' segments capture a decoded value, a trailing '*' captures the rest of the path as params['*'], extra/missing segments or different static segments return null, and a trailing slash is ignored. createRouter(routes) takes [{ pattern, name }] and returns { current(), navigate(path), back(), forward(), subscribe(listener) }. current() is { path, name, params, query } for the first matching route (name null and params {} when nothing matches; query parsed from '?a=1&b=2'). navigate pushes onto an in-memory history (discarding any forward entries), back/forward move along it (and do nothing at the ends), and subscribers are called with the new state after each change; subscribe returns an unsubscribe function.
