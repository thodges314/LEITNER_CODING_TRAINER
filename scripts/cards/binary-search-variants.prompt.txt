Implement binary search algorithms in O(log n) time on sorted arrays:

### `binarySearch(sorted, target)`
- Searches for `target` in an ascending sorted array.
- Returns the 0-based index if `target` is present; otherwise returns `-1`.

### `lowerBound(sorted, target)`
- Returns the first index `i` such that `sorted[i] >= target`.
- Returns `sorted.length` if no such element exists.
- Correctly handles duplicate elements.

### `mySqrt(x)`
- Computes and returns the floor of the square root ($\lfloor\sqrt{x}\rfloor$) for a non-negative integer `x`.
- Must use binary search without calling `Math.sqrt`.
