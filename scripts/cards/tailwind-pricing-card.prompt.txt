### `PricingCard({ tier, onSelect }: PricingCardProps): JSX.Element | null`

## Description

```ts
interface PricingTier {
  name: string;
  price: number;
  period?: string; // defaults to '/mo'
  popular?: boolean;
  features: string[];
  ctaText?: string; // defaults to 'Get Started'
}

interface PricingCardProps {
  tier: PricingTier;
  onSelect?: (tier: PricingTier) => void;
}
```

Implement an interactive React component (`PricingCard`) styled with Tailwind CSS utility classes:

### Requirements

- **Card Container** (`<article>`):
  - Rounded corners, generous padding, border, and smooth transitions.
  - When `tier.popular` is `true`:
    - Highlighted with an accent border (e.g. indigo/blue) and a 2px ring.
    - Renders a pill `<span>` badge inside with text `"Most Popular"` in uppercase semibold extra-small white text on an accent background.
  - When `tier.popular` is `false` or omitted:
    - Neutral slate/gray border and subtle surface background.

- **Header Section**:
  - Tier name (`<h3>`): large bold heading displaying `tier.name`.
  - Price row (`<div>` with top margin and baseline flex alignment):
    - Price (`<span>`): large extrabold display text displaying `$${tier.price}`.
    - Period (`<span>`): small muted text with left margin displaying `tier.period || '/mo'`.

- **Features List** (`<ul>`):
  - Vertically spaced list with vertical margin where each item in `tier.features` renders as a small flex-aligned `<li>` containing a `<span>` with the feature text.
  - When `tier.features` is empty or omitted, renders an empty `<ul>`.

- **Call-to-Action Button** (`<button type="button">`):
  - Full-width, padded, rounded corners, medium font weight, color transition, and pointer cursor.
  - When `tier.popular` is `true`: accent background (e.g. indigo/blue) with hover state and white text.
  - When `tier.popular` is `false` or omitted: neutral dark background with hover state and white text.
  - Content: `tier.ctaText || 'Get Started'`
  - Optional `onSelect` callback: when provided, clicking the button invokes `onSelect(tier)`.
