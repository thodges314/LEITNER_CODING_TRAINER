Write getProtoChain(obj): an array of the objects on obj's prototype chain, nearest first, ending with Object.prototype (empty for Object.create(null)).

Write findOwner(obj, key): the first object on the chain starting at obj itself that has key as an OWN property, or null.

Write myInstanceOf(value, Ctor) without using the instanceof operator: throw TypeError('Right-hand side is not callable') if Ctor is not a function; if Ctor has a custom [Symbol.hasInstance] (one that is not the default Function.prototype[Symbol.hasInstance]) return its boolean result; otherwise walk the chain of value and compare with Ctor.prototype (primitives and null are never instances).
