Write simpleStringify(value) that mimics JSON.stringify for primitives and arrays only: null -> "null", booleans -> "true"/"false", finite numbers via String, NaN/Infinity -> "null", strings wrapped in double quotes with \, " and newline escaped as \\, \" and \n, arrays as [a,b,c] with no spaces (nested arrays recurse; an undefined element becomes null). A top-level undefined returns undefined. You do not need to handle objects. Do not call JSON.stringify.
