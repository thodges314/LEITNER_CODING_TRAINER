Implement a lightweight stringifier for primitive types and arrays without calling `JSON.stringify`:

### `simpleStringify(value)`
- **Primitives**:
  - `null` -> `'null'`
  - Booleans -> `'true'` / `'false'`
  - Finite numbers -> `String(value)`
  - `NaN`, `Infinity`, `-Infinity` -> `'null'`
  - Strings -> wrapped in double quotes with `\`, `"`, and newline characters escaped as `\\`, `\"`, and `\n`.
  - Top-level `undefined` returns `undefined`.
- **Arrays**:
  - Serialized as `'[a,b,c]'` with no spaces.
  - Recursively serializes nested arrays.
  - Elements evaluating to `undefined` are serialized as `'null'`.
