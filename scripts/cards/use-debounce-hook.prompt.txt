Write two hooks. useDebounce(value, delay): returns the initial value immediately, then the latest value only after it has been stable for delay ms; clear the timer on change and unmount, and always use the latest delay. useThrottle(value, interval): the returned value changes at most once per interval — a change arriving after the interval has elapsed since the last update is applied immediately, otherwise it is delivered at the end of the interval carrying the LATEST value (intermediate values are skipped).
