## Description

Build a responsive e-commerce product card component in React styled with modern Tailwind CSS utility classes. The component should adapt seamlessly from a vertical stacked layout on mobile screens (`flex-col`) to a horizontal side-by-side layout on desktop viewports (`md:flex-row`).

```ts
interface Product {
  title: string;
  description: string;
  price: number;
  originalPrice?: number;
  badge?: string;
  imageUrl?: string;
  rating?: number;
}

interface ResponsiveCardProps {
  product: Product;
  onAddToCart?: () => void;
}
```

### `ResponsiveProductCard({ product, onAddToCart }: ResponsiveCardProps): JSX.Element | null`

#### Parameters
- `product`: `Product` — An object containing product details (title, description, price, optional originalPrice, optional badge, optional imageUrl, optional rating). Returns `null` if `product` is undefined or null.
- `onAddToCart`: `(() => void) | undefined` — Optional callback invoked when the user clicks the "Add to Cart" button.

#### Structural & Styling Requirements
- **Root Element**:
  - Semantic `<article>` element using a vertical flex column on mobile and a horizontal flex row at the `md` breakpoint.
  - Styled with rounded corners, subtle border, neutral surface background, clipped overflow, and shadow.
- **Media / Image Section**:
  - Relative container spanning full width with a 16:9 aspect ratio on mobile, switching to a fixed-width non-shrinking square (`md:w-48 md:aspect-square`) at the `md` breakpoint.
  - Child `<img>` filling the container and cropped to cover, using `product.imageUrl` (fallback to `'/keyboard-preview.jpeg'` if omitted) and `alt={product.title}`.
  - If `product.badge` is provided, render an absolute overlay pill (`<span>`) anchored in the top-left corner with accent background, white extra-small semibold text, compact padding, and pill rounding.
- **Content Section**:
  - Flexible container growing to fill remaining space with padding and vertical flex spacing between header and CTA.
  - Heading (`<h3>`): large bold title displaying `product.title`.
  - Description (`<p>`): small muted text with top margin and 2-line clamping displaying `product.description`.
  - Price & Rating Row (flex row spaced apart with top margin):
    - Price container (baseline-aligned flex row):
      - Current price (`<span>`): extra-large extrabold text displaying `$${product.price}`.
      - If `product.originalPrice` is provided: small muted strikethrough `<span>` with left margin displaying `$${product.originalPrice}`.
    - If `product.rating` is provided: inline rating container with amber/yellow small medium text.
  - Add to Cart button:
    - `<button type="button" onClick={onAddToCart}>` labeled `"Add to Cart"`, full-width on mobile and auto-width at the `md` breakpoint, with padding, rounded corners, accent background + hover state, white medium text, transition, and pointer cursor.

#### Edge Cases
- When `product` is nullish, return `null`.
- When `badge`, `originalPrice`, or `rating` are not provided, omit their respective elements without rendering empty tags.
