## Description

Build a responsive e-commerce product card component in React styled with modern Tailwind CSS utility classes. The component should adapt seamlessly from a vertical stacked layout on mobile screens (`flex-col`) to a horizontal side-by-side layout on desktop viewports (`md:flex-row`).

```ts
interface Product {
  title: string;
  description: string;
  price: number;
  originalPrice?: number;
  badge?: string;
  imageUrl?: string;
  rating?: number;
}

interface ResponsiveCardProps {
  product: Product;
  onAddToCart?: () => void;
}
```

### `ResponsiveProductCard({ product, onAddToCart }: ResponsiveCardProps): JSX.Element | null`

#### Parameters
- `product`: `Product` — An object containing product details (title, description, price, optional originalPrice, optional badge, optional imageUrl, optional rating). Returns `null` if `product` is undefined or null.
- `onAddToCart`: `(() => void) | undefined` — Optional callback invoked when the user clicks the "Add to Cart" button.

#### Structural & Styling Requirements
- **Root Element**:
  - Semantic `<article>` element using `flex flex-col` on mobile and `md:flex-row` on desktop.
  - Styled with rounded corners, subtle border, neutral surface background, `overflow-hidden`, and shadow.
- **Media / Image Section**:
  - Relative container spanning `w-full aspect-video` on mobile and switching to `md:w-48 md:aspect-square md:shrink-0` on desktop.
  - Child `<img>` filling the container with `object-cover`, using `product.imageUrl` (fallback to `'/keyboard-preview.jpeg'` if omitted) and `alt={product.title}`.
  - If `product.badge` is provided, render an absolute overlay pill (`<span>`) anchored at top-left (`absolute top-3 left-3`) with accent background, white extra-small semibold text, compact padding, and `rounded-full`.
- **Content Section**:
  - Flexible container (`flex-1`) with padding and `flex flex-col justify-between`.
  - Heading (`<h3>`): large bold title displaying `product.title`.
  - Description (`<p>`): small muted text with top margin and 2-line truncation (`line-clamp-2`) displaying `product.description`.
  - Price & Rating Row (`flex items-center justify-between` with top margin):
    - Price container (`flex items-baseline`):
      - Current price (`<span>`): extra-large extrabold text displaying `$${product.price}`.
      - If `product.originalPrice` is provided: small muted strikethrough (`line-through`) `<span>` with left margin displaying `$${product.originalPrice}`.
    - If `product.rating` is provided: inline rating container with amber/yellow small medium text.
  - Add to Cart button:
    - `<button type="button" onClick={onAddToCart}>` labeled `"Add to Cart"`, full-width on mobile and auto-width on desktop (`w-full md:w-auto`), with padding, rounded corners, accent background + hover state, white medium text, transition, and pointer cursor.

#### Edge Cases
- When `product` is nullish, return `null`.
- When `badge`, `originalPrice`, or `rating` are not provided, omit their respective elements without rendering empty tags.
