Implement a standalone reducer function from scratch:

### `myReduce<T, U = T>(array: T[], callback: (accumulator: U, value: T, index: number, array: T[]) => U, initialValue?: U): U`
- Iterates over `array`, invoking `callback(accumulator, value, index, array)`.
- **Initial Value Handling**:
  - If `initialValue` is provided (`arguments.length >= 3`):
    - Starts with `accumulator = initialValue`.
    - Begins processing from index `0`.
    - If `array` is empty, returns `initialValue`.
  - If `initialValue` is omitted:
    - Sets `accumulator = array[0]`.
    - Begins processing from index `1`.
    - Throws a `TypeError('Reduce of empty array with no initial value')` if `array` is empty.
- Skips sparse holes (checks `i in array`).
- Returns the final accumulated value.
