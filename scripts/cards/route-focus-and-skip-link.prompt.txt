Build `Layout({ path, title, children })` for accessible client-side routing:

- **DOM Structure (in exact order)**:
  1. Skip link: `<a href="#main-content">Skip to main content</a>`.
  2. Main landmark: `<main id="main-content" tabIndex={-1}>`.
  3. Heading: `<h1 tabIndex={-1}>{title}</h1>` inside `<main>`, followed by `children`.
- **Skip Link Interaction**: Clicking the skip link prevents default browser hash scrolling and programmatically moves focus to `<main>`.
- **Document Title**: Keep `document.title` synchronized to `${title} | My App`.
- **Route Change Focus**: When `path` changes (excluding initial mount, and not when only `title` or `children` change), move focus to `<h1>` so keyboard and screen-reader users land at the top of the new page.
