## Description

```ts
interface KeyedItem {
  id: string;
}
```

### `updateKeyedBars(svg: SVGSVGElement, items?: KeyedItem[]): d3.Selection`

The **Enter–Update–Exit data join** (`selection.data(items, keyFn).join(enter, update, exit)`) is D3's core paradigm. By supplying a key function `(d) => d.id`, D3 reconciles incoming data to existing DOM elements by identity instead of array index. Surviving elements are preserved (`update`), new elements are created (`enter`), and elements without matching data are removed (`exit`).

Implement `updateKeyedBars` to bind `items` to SVG `<g class="box">` elements with a centered label.

### Requirements

1. **Keyed Data Binding**:
   - Default `items = []` and safely guard against `undefined` or non-array inputs (treat as empty array `[]`).
   - Select all existing `g.box` elements in `svg` and bind items using identity key `(d) => d.id`.

2. **Enter, Update, Exit**:
   - Use `.join(enter, update, exit)`:
     - **Enter**: Append a `<g>` with `class="box"` and `data-id={d.id}`. Inside each group, append:
       - `<rect>`: `width="40"`, `height="40"`, `fill="steelblue"`.
       - `<text>`: `x="20"`, `y="25"`, `text-anchor="middle"`, `fill="white"`, and text content set to `d.id`.
     - **Update**: Preserve existing matching elements.
     - **Exit**: Remove unkeyed elements using `.remove()`.

3. **Position Ordering**:
   - For all merged groups (entered + updated), set `transform` to `translate(${i * 50}, 10)` where `i` is the item index.
   - Return the selection.
