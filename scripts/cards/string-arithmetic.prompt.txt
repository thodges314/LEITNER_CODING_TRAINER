Implement arbitrary-precision string arithmetic without converting whole strings to numbers:

> **Important**: Do not use `BigInt` or `Number()` on whole strings; process digit by digit.

### `addBinary(a, b)`
- Adds two binary number strings `a` and `b` and returns their sum as a binary string (e.g. `'11'` + `'1'` -> `'100'`).

### `addStrings(a, b)`
- Adds two non-negative decimal number strings `a` and `b` of arbitrary length and returns their sum as a string (e.g. `'999'` + `'1'` -> `'1000'`).

### `multiplyStrings(a, b)`
- Multiplies two non-negative decimal strings `a` and `b` and returns the product as a string (e.g. `'123'` * `'456'` -> `'56088'`).
- If either factor is `'0'`, returns `'0'`.
- Resulting strings must contain no leading zeros except for `'0'` itself.
