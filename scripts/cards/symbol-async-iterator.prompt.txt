Write createAsyncRange(start, end, delayMs = 0): returns an object with a [Symbol.asyncIterator]() method that yields numbers from start up to (but not including) end. Each call to next() returns a Promise resolving to { value, done } after an optional delay of delayMs milliseconds. Write collectAsync(asyncIterable): consumes an async iterable using for await (const item of asyncIterable) and returns a Promise resolving to an array of all collected items. Write mapAsyncIterable(asyncIterable, fn): returns an async iterable object whose [Symbol.asyncIterator]() yields await fn(item) for each item.
