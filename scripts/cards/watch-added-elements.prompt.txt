Write watchForElements(root, selector, onFound, MO = MutationObserver) that calls onFound(element) for every element matching selector inside root: first for the ones already there (in document order, found with root.querySelectorAll), then for each one added later. Create one observer with new MO(callback) and observe root with { childList: true, subtree: true }. For every added node (mutation.addedNodes of every mutation in the batch): ignore anything that is not an element (nodeType !== 1, such as text); report the node itself if node.matches(selector), then its matching descendants (node.querySelectorAll(selector)). An element is reported at most once, even if the same node is delivered again. Return a stop function that disconnects the observer.
