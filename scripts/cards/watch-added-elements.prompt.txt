### watchForElements(root: Element, selector: string, onFound: (element: Element) => void, MO?: MutationObserverConstructorLike): () => void
Write `watchForElements(root, selector, onFound, MO = MutationObserver)`:

- **Initial Discovery**: Calls `onFound(element)` for all matching elements already present in `root` in document order (`root.querySelectorAll(selector)`).
- **Mutation Observation**:
  - Initializes a `new MO(callback)` and observes `root` with `{ childList: true, subtree: true }`.
  - For each `addedNode` across all mutations in the batch:
    - Ignore non-element nodes (`node.nodeType !== 1`).
    - If `node.matches(selector)`, report the element via `onFound(node)`.
    - Report any matching descendants found via `node.querySelectorAll(selector)`.
- **Deduplication**: Each unique element is reported at most once, even if delivered across multiple mutation records.
- **Cleanup**: Returns a `stop()` function that disconnects the observer.
