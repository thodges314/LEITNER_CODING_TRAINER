Write createSequenceMatcher(bindings, timeoutMs = 1000) for GitHub/vim-style key sequences such as "g i". bindings maps a space-separated sequence to an action name, for example { 'g i': 'goIssues', 'g p': 'goPulls', '?': 'help' }; no sequence is a prefix of another. It returns press(key, now), where now is a timestamp in milliseconds. press returns the action name when the key completes a sequence, and null otherwise. Rules: (1) if more than timeoutMs have passed since the previous key (exactly timeoutMs is still in time), the partial sequence is forgotten first; (2) a key that continues the partial sequence advances it; (3) a key that does not continue it starts over, and may itself be the first key of a new sequence ('g', 'g', 'i' still completes 'g i'); (4) after a match the matcher starts fresh. The timeout is measured from the previous key, not from the first key of the sequence.
