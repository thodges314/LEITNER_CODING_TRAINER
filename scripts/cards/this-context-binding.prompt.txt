Write createGreeter(name): returns an object with property name, method greet() returning 'Hello, ' + this.name, and method getBoundGreet() returning greet permanently bound to that instance (so even when detached and called without a receiver, it returns 'Hello, ' + this.name). Write invokeWithContext(fn, context, ...args): invokes fn with context as its this value and passes args, without using Function.prototype.call or Function.prototype.apply (e.g. using Reflect.apply or assigning fn to a unique Symbol on context). Write isConstructorCall(TargetClass, ...args): returns true if new TargetClass(...args) constructs an instance of TargetClass; returns false if calling TargetClass without new would throw or if TargetClass is not a valid constructor.
