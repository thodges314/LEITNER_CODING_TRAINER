Implement string segmentation and decoding algorithms using dynamic programming:

### `wordBreak(s, wordDict)`
- Determines whether string `s` can be segmented into a space-separated sequence of one or more dictionary words from `wordDict`.
- Dictionary words may be reused multiple times.
- Returns `true` for an empty string `""`.

### `numDecodings(s)`
- Calculates the total number of ways to decode a string of digits `s`, where `'A' = "1"`, ..., `'Z' = "26"`.
- Valid single digits range from `'1'` to `'9'`; valid two-digit pairings range from `'10'` to `'26'`.
- A leading or invalid `'0'` (such as in `"06"`) cannot be decoded and yields `0`.
