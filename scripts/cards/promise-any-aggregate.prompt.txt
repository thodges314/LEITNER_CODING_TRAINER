Write `promiseAny(promises)`:

### `promiseAny<T>(promises: Iterable<T | Promise<T>>): Promise<T>`
- **Input**: Takes an iterable of promises (or plain values).
- **Fulfillment**: Returns a Promise that fulfills as soon as **any** input promise fulfills, resolving with that first fulfillment value.
- **Rejection & `AggregateError`**:
  - If **ALL** input promises reject (or if the iterable is empty), the returned Promise rejects with an `AggregateError`.
  - The `AggregateError` must have `message: 'All promises were rejected'`.
  - Its `.errors` property contains all rejection reasons in their original input order.
