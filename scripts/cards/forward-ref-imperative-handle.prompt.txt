Build a specialized input component using `forwardRef` and `useImperativeHandle`:

### FancyInput(props: FancyInputProps, ref: React.Ref<FancyInputHandle>): JSX.Element
- Wrapped with `forwardRef((props, ref) => ...)`.
- Renders an `<input ref={inputRef} {...props} />` passing through props (such as `placeholder`, `type`, etc.).
- Instead of exposing the raw DOM element, exposes an imperative handle object via `useImperativeHandle(ref, () => ({ ... }), [])`.

#### Imperative Ref API
The forwarded ref must expose **only** these three methods (and must not be the DOM element itself):
- **`focus()`**: Focuses the underlying input element.
- **`clear()`**: Clears the input text (`value = ''`) and focuses the element.
- **`getValue()`**: Returns the input element's current text value.
