#### Banner Structure & Tailwind Classes

- **Banner Container (`<div class="...">`)**:
  - Flex layout spacing content across, with padding, rounded corners, subtle shadow, and light blue tinting: `flex items-center justify-between gap-4 p-4 rounded-xl bg-blue-50 border border-blue-200 text-blue-900 shadow-sm`
  - Accessibility role: `role="alert"`
- **Content Group (`<div class="...">`)**:
  - Flex layout aligning an icon badge with message text: `flex items-center gap-3`
  - **Icon Badge (`<span class="...">`)**:
    - Centered badge with background and bold text: `<span class="inline-flex items-center justify-center w-8 h-8 rounded-lg bg-blue-100 text-blue-600 font-bold text-sm">i</span>`
  - **Text Container (`<div>`)**:
    - Headline: `<h4 class="font-semibold text-sm">System Update Available</h4>`
    - Subtext caption: `<p class="text-xs text-blue-700">A new version of the dashboard is ready for deployment.</p>`
- **Action Button (`<button class="...">`)**:
  - Type attribute: `type="button"`
  - Styled interactive button: `<button type="button" class="px-3 py-1.5 rounded-lg text-xs font-medium text-white bg-blue-600 hover:bg-blue-700 transition-colors focus:outline-none focus:ring-2 focus:ring-blue-500">Update Now</button>`
