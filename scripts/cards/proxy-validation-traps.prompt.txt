Write createValidated(target, schema) where schema maps property names to predicate functions. Return a Proxy with: a set trap that throws TypeError('Unknown property: <key>') for keys not in the schema, throws TypeError('Invalid value for <key>') when the predicate rejects the value, and otherwise stores the value and returns true; a deleteProperty trap that throws TypeError('Cannot delete <key>') for schema keys but allows other deletes; a has trap and an ownKeys trap that hide every key starting with '_' (so '_secret' in p is false and Object.keys(p) omits it).
