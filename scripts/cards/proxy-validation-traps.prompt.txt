Implement schema-validated and private-field proxy traps:

### `createValidated(target, schema)`
- Wraps `target` in a `Proxy` enforcing schema rules and property privacy.
- `schema` is an object mapping allowed property names to validator predicates (`(value) => boolean`).

#### Traps & Behaviors
- **`set` Trap**:
  - Throws `TypeError('Unknown property: <key>')` if `key` is not defined in `schema`.
  - Throws `TypeError('Invalid value for <key>')` if `schema[key](value)` returns false.
  - Otherwise assigns the value via `Reflect.set(target, key, value, receiver)`.
- **`deleteProperty` Trap**:
  - Throws `TypeError('Cannot delete <key>')` if attempting to delete a key present in `schema`.
  - Permits deletion of non-schema properties via `Reflect.deleteProperty`.
- **`has` & `ownKeys` Traps (Privacy)**:
  - Any key starting with an underscore `'_'` is considered private.
  - The `has` trap returns `false` for keys starting with `'_'`.
  - The `ownKeys` trap filters out keys starting with `'_'` so they never appear in `Object.keys()` or enumeration.
