Implement HTTP cookie parsing and serialization utilities:

### `parseCookies(header: string | null | undefined): Record<string, string>`
- Parses a `Cookie` request header or `document.cookie` string (e.g. `'a=1; b=hello%20world'`).
- Returns an object mapping cookie names to decoded values:
  - Splits segments on `';'` and skips empty segments.
  - Splits each segment at the **first `'='` only** (cookie values may contain equal signs).
  - Trims both name and value.
  - Decodes values with `decodeURIComponent` (if decoding throws, preserves the raw text).
  - Preserves the **first** occurrence if a cookie name is duplicated.

### `serializeCookie(name: string, value: string, options?: CookieOptions): string`
- Generates a `Set-Cookie` header string: `name=encodeURIComponent(value)`.
- **Validation**:
  - Throws `TypeError('Invalid cookie name')` if `name` is empty or contains `'='`, `';'`, `','`, or whitespace.
  - If `options.sameSite` is provided, accepts case-insensitive `'strict'`, `'lax'`, or `'none'`. Throws `TypeError('Invalid SameSite value')` for any other value.
- **Attributes Ordering** (appends provided attributes in this exact order):
  1. `; Max-Age=<n>` (integer from `options.maxAge`; note: `0` must be emitted).
  2. `; Expires=<utc string>` (`options.expires.toUTCString()`).
  3. `; Domain=<domain>`.
  4. `; Path=<path>`.
  5. `; Secure` (if `options.secure === true`).
  6. `; HttpOnly` (if `options.httpOnly === true`).
  7. `; SameSite=<Strict|Lax|None>` (capitalized: `'Strict'`, `'Lax'`, or `'None'`).
