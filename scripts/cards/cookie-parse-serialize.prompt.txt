Write parseCookies(header) and serializeCookie(name, value, options = {}). parseCookies reads a Cookie header or document.cookie string such as 'a=1; b=hello%20world' and returns an object: split on ';', skip empty segments, split each segment at the FIRST '=' (values may contain '='), trim the name and the value, decode the value with decodeURIComponent (if it is malformed, keep the raw text), and keep the first value when a name repeats. serializeCookie returns the Set-Cookie text: name=encodeURIComponent(value), followed by the attributes that were provided, always in this order: '; Max-Age=<n>' (maxAge, a number: 0 must still be written), '; Expires=<utc string>' (expires, a Date, via toUTCString), '; Domain=<d>' (domain), '; Path=<p>' (path), '; Secure' (secure: true), '; HttpOnly' (httpOnly: true), '; SameSite=<Strict|Lax|None>' (sameSite, case-insensitive input). It throws TypeError('Invalid cookie name') for an empty name or a name containing '=', ';', ',' or whitespace, and TypeError('Invalid SameSite value') for any other SameSite value.
