Implement a custom React hook `useMediaQuery(query)` that listens for responsive viewport changes.

- **Parameter**: Accepts a CSS media query string (e.g. `'(min-width: 768px)'`).
- **Initial State**: Initializes boolean state using `window.matchMedia(query).matches` (defaulting to `false` if `window.matchMedia` is undefined).
- **Event Listener**: Registers a change listener on the media query list (`addEventListener` with fallback to `addListener`).
- **State Updates**: Updates `matches` boolean state when the media query status changes.
- **Cleanup**: Removes event listeners when the component unmounts or when the `query` string changes.
