Write a custom hook for fetching JSON data from a URL:

### `useFetch(url)`
- Returns `{ data, loading, error }`.

#### Lifecycle & State Progression
- **Initial Render**:
  - Starts as `{ data: null, loading: true, error: null }`.
  - Initiates a network request via `fetch(url)` in a `useEffect`.
- **Successful Fetch**:
  - Updates state to `{ data, loading: false, error: null }` with the parsed JSON body.
- **Error Handling**:
  - On non-2xx HTTP responses (`!res.ok`), throws an `Error` whose message mentions the HTTP status code (e.g. `HTTP ${res.status}`).
  - On HTTP or network errors, updates state to `{ data: null, loading: false, error }`.
- **URL Dependency**:
  - When `url` changes, resets state to `{ data: null, loading: true, error: null }` and fetches the new URL.
  - Re-rendering with the same `url` must **not** re-trigger the fetch.
