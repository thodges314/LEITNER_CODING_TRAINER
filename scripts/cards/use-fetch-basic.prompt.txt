Write a custom hook useFetch(url) that loads JSON for a url. It returns { data, loading, error }.

- On the first render it is { data: null, loading: true, error: null } and a request for url has been started (call fetch(url) once).
- When the request succeeds it becomes { data, loading: false, error: null } with the parsed JSON.
- A non-2xx response, or a network failure, gives { data: null, loading: false, error } where error is an Error (for an HTTP error its message mentions the status, e.g. 'HTTP 404').
- When url changes the hook fetches the new url, goes back to loading (data and error cleared) while it runs, and then shows the new result. Re-rendering with the same url must not fetch again.

You do not need to cancel old requests here; the harder useFetch card covers aborting and stale responses.
