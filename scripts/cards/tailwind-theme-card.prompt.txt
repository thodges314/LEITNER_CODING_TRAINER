```ts
interface ThemeCardProps {
  title: string;
  description: string;
  badge?: string;
}
```

Build a theme-adaptive card using Tailwind `dark:` variants so it adapts cleanly between Light and Dark mode:

> [!TIP]
> Flip the theme toggle in the app's top bar to test how your card adapts between Light and Dark mode in the Live Preview.

### `ThemeCard({ title, description, badge }: ThemeCardProps): JSX.Element`
- **Container** (`<article>`):
  - Rounded card with padding, a `1px` border, and smooth color transitions (`transition-colors`).
  - Surface & border palette: **light** `white` background with `slate-200` border; **dark** `slate-900` background with `slate-700` border.
- **Header** (`<h3>` + optional `<span>`):
  - Render `title` in an `<h3>` with semibold base text (`slate-900` in light mode, `slate-100` in dark mode).
  - When `badge` is provided, render a pill `<span>` beside the title using a translucent indigo background (`indigo-500/15`) and `indigo-600` text in light mode / `indigo-300` in dark mode. Omit the `<span>` when `badge` is not provided.
- **Description** (`<p>`):
  - Render `description` in a `<p>` below the header with small text (`slate-600` in light mode, `slate-300` in dark mode).
