An optimistic UI shows the result of an action immediately and fixes it when the server answers. Write the pure state helpers (none of them changes its inputs). Items are objects with an id.

toggleLike(post): for a post { id, liked, likes } return a new post with liked flipped and likes one higher (when it was not liked) or one lower (when it was).
applyOptimistic(items, id, patch): a new array where the item with that id is replaced by a copy with patch merged in and pending: true. All other items stay the very same objects.
confirmOptimistic(items, id, serverItem): replace the item with that id by a copy of serverItem with pending: false.
rollbackOptimistic(items, id, original): put original back in place of the item with that id, exactly as it was (no pending flag).

An id that is not in the list changes nothing.
