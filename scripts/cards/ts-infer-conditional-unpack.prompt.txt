Define advanced conditional utility types using the `infer` keyword:

### `MyReturnType<T>`
- Extracts the return type of function type `T`.
- Evaluates to `never` if `T` is not a function.

### `MyParameters<T>`
- Extracts the parameter tuple type of function type `T`.
- Evaluates to `never` if `T` is not a function.

### `DeepAwaited<T>`
- Recursively unwraps nested `Promise` or `PromiseLike` types (e.g., `Promise<Promise<number>>` unwraps to `number`).
- Evaluates to `T` if it is not a `PromiseLike`.

### `TupleToUnion<T>`
- Extracts a union of all element types from tuple or array type `T`.

### `Flatten<T>`
- Unwraps one array layer if `T` is an array type (`(infer U)[] -> U`).
- Returns `T` unchanged if it is not an array.
