```ts
interface AccordionItem {
  id: string;
  title: string;
  content: string;
}

interface AccordionProps {
  items: AccordionItem[];
  allowMultiple?: boolean;
}
```

Build an accessible accordion where items can be expanded and collapsed:

### Accordion({ items, allowMultiple = false }: AccordionProps): JSX.Element
- `items`: array of `AccordionItem` objects (`[{ id, title, content }]`).
- `allowMultiple`: optional boolean (defaults to `false`). When `true`, multiple panels can stay open at once; when `false`, opening one panel closes any currently open panel.
- **Accessibility & ARIA**:
  - All panels start closed.
  - Use `useId()` to ensure unique IDs across component instances.
  - For each item, render a heading `<h3>` containing `<button id={buttonId} aria-expanded={isOpen} aria-controls={panelId}>` displaying the item's `title`.
  - The content panel is `<div role="region" id={panelId} aria-labelledby={buttonId}>{item.content}</div>`, rendered **only** while that item is open.
- **Interactions**:
  - Clicking a button toggles its open state (clicking an open panel's button closes it).
