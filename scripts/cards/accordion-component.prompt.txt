```ts
interface AccordionItem {
  id: string;
  title: string;
  content: string;
}
```

Build an accessible accordion where items can be expanded/collapsed:

### Accordion({ items, allowMultiple = false }: { items: AccordionItem[]; allowMultiple?: boolean }): JSX.Element:
- `items` is an array of `AccordionItem` (`[{ id, title, content }]`).
- For each item, render a heading `<h3>` containing `<button id="<buttonId>" aria-expanded aria-controls="<panelId>">` with the title, followed by its panel `<div role="region" id="<panelId>" aria-labelledby="<buttonId>">` (rendered **ONLY** while open). Use `useId` so IDs are unique per component instance.
- All panels start closed.
- Clicking a title opens its panel; by default opening one closes the others; clicking an open title closes it.
- With `allowMultiple={true}`, several panels may remain open simultaneously.
