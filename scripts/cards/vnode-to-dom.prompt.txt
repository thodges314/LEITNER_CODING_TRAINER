Implement a lightweight virtual DOM to real DOM compiler and renderer:

### createDom(vnode: VNode): Node
- Converts a virtual node tree into real DOM nodes.
- **Primitives**:
  - `string` or `number`: creates a safe text node via `document.createTextNode(String(vnode))` (never parsed as HTML).
  - `null`, `undefined`, or `boolean`: returns an empty text node (`document.createTextNode('')`).
- **Elements**:
  - Creates the element with `document.createElement(vnode.type)`.
  - **Props Handling**:
    - `className`: sets the `'class'` attribute.
    - `style`: copies style properties onto `el.style` (`Object.assign(el.style, value)`).
    - Event handlers (e.g. `onClick`, `onInput`): attaches listener via `el.addEventListener(event, fn)`.
    - `true`: sets attribute to empty string `''`.
    - `false`, `null`, or `undefined`: attribute is omitted.
    - Other values: calls `el.setAttribute(key, String(value))`.
  - **Children**:
    - Recursively flattens and renders `vnode.children || []` (handles arbitrarily nested arrays).

### render(vnode: VNode, container: HTMLElement): void
- Compiles `vnode` via `createDom(vnode)` and replaces the container's contents using `container.replaceChildren(...)`.
