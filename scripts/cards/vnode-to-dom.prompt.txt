Write createDom(vnode) turning a tree of { type, props, children } objects into real DOM nodes.

Write render(vnode, container) that replaces the container's content with the result. Strings and numbers become text nodes (never parsed as HTML); null, undefined and booleans render nothing; children may be nested arrays. Props: className -> the class attribute, style (object) -> element.style, onClick-style functions -> addEventListener('click', ...), true -> an empty attribute, false/null/undefined -> skipped, everything else -> setAttribute.
