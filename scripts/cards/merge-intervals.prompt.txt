Implement interval merging on an array of `[start, end]` pairs in $O(n \log n)$ time:

### `mergeIntervals(intervals: [number, number][]): [number, number][]`
Given a list of ranges `[start, end]` (such as calendar meetings or numeric spans; input may be unsorted), combine any ranges that **overlap** or **touch at an endpoint** into a minimal list of non-overlapping ranges sorted by start position.
- **Examples**:
  - `mergeIntervals([[1, 3], [2, 6], [8, 10], [15, 18]])` $\to$ `[[1, 6], [8, 10], [15, 18]]` (`[1, 3]` and `[2, 6]` overlap).
  - `mergeIntervals([[1, 4], [4, 5]])` $\to$ `[[1, 5]]` (touching at `4` still merges).
- **Edge Case**: Returns `[]` if `intervals` is empty.
