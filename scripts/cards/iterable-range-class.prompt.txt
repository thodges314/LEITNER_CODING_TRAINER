Write class Range with constructor(start, end, step = 1) that is iterable through [Symbol.iterator]: it yields start, start + step, ... while the value is before end (end is exclusive; a negative step counts down while the value is greater than end). It must be re-iterable (a second loop starts over), and a step of 0 throws a RangeError whose message contains 'step'. Also write take(iterable, n) returning an array of the first n values of any iterable (fewer if it ends sooner) without consuming the rest — it must work on infinite generators.
