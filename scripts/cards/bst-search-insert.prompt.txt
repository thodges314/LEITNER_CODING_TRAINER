Implement core Binary Search Tree (BST) operations on nodes shaped `{ val, left, right }` (where `left.val < node.val < right.val`, with no duplicates):

### `searchBST(root: TreeNode<number> | null, val: number): TreeNode<number> | null`
- Searches for a node with value `val` in the BST.
- Returns the matching node object, or `null` if not found or if `root` is null.
- Operates in O(h) time complexity.

### `insertBST(root: TreeNode<number> | null, val: number): TreeNode<number>`
- Inserts `val` into the BST at the appropriate position and returns the tree `root`.
- If `root` is `null`, returns a new node `{ val, left: null, right: null }`.
- If `val` already exists in the BST, leaves the tree unchanged and returns `root`.

### `findMin(root: TreeNode<number> | null): number | undefined`
- Traverses to the leftmost node and returns the minimum value (`val`) in the BST.
- Returns `undefined` if `root` is null (empty tree).

### `findMax(root: TreeNode<number> | null): number | undefined`
- Traverses to the rightmost node and returns the maximum value (`val`) in the BST.
- Returns `undefined` if `root` is null (empty tree).
