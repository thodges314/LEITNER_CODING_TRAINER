Implement two asynchronous control-flow utilities: `makeCancelable` and `withTimeout`.

### `makeCancelable(promise)`
- Wraps an input promise and returns an object `{ promise, cancel }`.
- If `cancel()` is invoked while the promise is still pending, the wrapped promise rejects with `{ isCanceled: true }`.
- If the promise has already fulfilled or rejected prior to calling `cancel()`, its final settlement is preserved unchanged.

### `withTimeout(promise, ms, timeoutError = new Error('Timeout'))`
- Returns a Promise that settles with the outcome of `promise` if it settles within `ms` milliseconds.
- If `ms` elapses before the promise settles, rejects with `timeoutError`.
- If `promise` settles first, clears the timer handle to prevent resource leaks.
