Write makeCancelable(promise): wraps a promise and returns an object { promise: wrappedPromise, cancel() }. If cancel() is called while the promise is still pending, wrappedPromise rejects with an object { isCanceled: true }. If the promise already resolved or rejected before cancel() was called, its result remains unchanged.

Write withTimeout(promise, ms, timeoutError = new Error('Timeout')): returns a Promise that settles with the result of promise if it finishes within ms; otherwise rejects with timeoutError. If promise settles before the timer expires, the timer is cleared to avoid leaking handles.
