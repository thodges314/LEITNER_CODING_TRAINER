Implement shortest path searches over implicit state graphs using BFS:

### `ladderLength(beginWord: string, endWord: string, wordList: string[]): number`
- Finds the number of words on the shortest transformation sequence from `beginWord` to `endWord`.
- Each step changes exactly one lowercase letter, and every intermediate word must exist in `wordList`.
- `beginWord` does not need to be in `wordList`.
- Returns `0` if `endWord` is not in `wordList` or if no valid transformation sequence exists.

### `minMutation(start: string, end: string, bank: string[]): number`
- Finds the minimum number of single-character mutations ('A', 'C', 'G', 'T') to convert gene string `start` to `end`.
- Every mutated gene must exist in `bank`.
- Returns `0` if `start === end`, or `-1` if impossible.

### `openLock(deadends: string[], target: string): number`
- Computes the minimum number of circular dial turns (`0` through `9`, wrapping around) to reach `target` starting from `'0000'`.
- Any combination in array `deadends` is blocked and cannot be visited.
- Returns `-1` if unreachable or if `'0000'` is in `deadends`; returns `0` if `target === '0000'`.
