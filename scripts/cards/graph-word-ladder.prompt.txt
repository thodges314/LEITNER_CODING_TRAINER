These are shortest-path problems on implicit graphs: states are strings and edges change one character. Write ladderLength(beginWord, endWord, wordList): the number of words on the shortest sequence from beginWord to endWord where each step changes one letter (lowercase) and every word after the first must be in wordList; beginWord need not be in the list; return 0 if endWord is not in the list or is unreachable. Write minMutation(start, end, bank): genes are strings over A, C, G, T; each step changes one character and must land in bank; return the fewest steps or -1 (0 when start equals end). Write openLock(deadends, target): a 4-wheel lock starts at '0000'; each move turns one wheel one step (9 wraps to 0 and 0 to 9); states in deadends are forbidden; return the fewest moves to reach target or -1 (-1 also when '0000' is a dead end).
