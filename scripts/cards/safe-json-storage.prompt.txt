Write safeParse(text, fallback) returning the parsed JSON or `fallback` when text is not valid JSON (or not a string). Write safeGet(storage, key, fallback) that reads storage.getItem(key) (a localStorage-like object) and returns the parsed value or fallback when the key is missing or the stored text is corrupt, and safeSet(storage, key, value) that stores JSON and returns true, or false if storage.setItem throws.
