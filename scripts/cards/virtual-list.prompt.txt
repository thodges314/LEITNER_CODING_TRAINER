Build VirtualList({ items, itemHeight, height, overscan = 3 }) for long lists of strings. Render <div role="list" style={{ height, overflowY: 'auto', position: 'relative' }} onScroll> containing ONE inner <div> whose style.height is items.length * itemHeight (the full scroll height, position: relative). Inside it render only the visible window: items from max(0, floor(scrollTop / itemHeight) - overscan) up to min(items.length, ceil((scrollTop + height) / itemHeight) + overscan), each as <div role="listitem"> with style position: absolute, top: index * itemHeight, height: itemHeight and the item text. Track scrollTop from the scroll event.
