List nodes are { val, next } (null ends the list).

Write reverseKGroup(head, k): reverse the nodes k at a time and return the new head; a final group shorter than k stays as it is (k >= 1).

Write reverseBetween(head, left, right): reverse only the nodes from position left to position right (1-indexed, inclusive) in one pass.

Write swapPairs(head): swap every two adjacent nodes by relinking nodes (not by changing values).
