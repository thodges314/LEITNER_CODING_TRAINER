Implement text segmentation for search-result highlighting:

### `highlightMatches(text, query)`
- Splits `text` into an array of consecutive segments `{ text, match }`.
- `match` is `true` for substrings matching `query` and `false` for non-matching text in between.
- **Matching Rules**:
  - **Case-Insensitive**: matching ignores case, but each segment preserves the exact original casing in `text`.
  - **Literal Text**: `query` is treated as literal plain text; regex characters (`.`, `*`, `+`, `?`, `^`, `$`, `(`, `)`, `[`, `]`, `{`, `}`, `|`, `\`) are matched literally.
  - **Non-Overlapping**: matches are consumed greedily from left to right without overlapping (e.g., `'aaa'` with query `'aa'` yields match `'aa'` followed by non-match `'a'`).
- **Edge Cases**:
  - No segment may have an empty `text: ''`.
  - If `text` is empty `''`, returns `[]`.
  - If `query` is empty `''`, returns `[{ text, match: false }]`.
  - Concatenating all segment `text` properties reconstructs the original `text`.
