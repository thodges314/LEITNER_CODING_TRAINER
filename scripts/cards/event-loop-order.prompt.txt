Write orderOfEvents() that returns a Promise resolving to the array of labels in the order they happen. Do, in this order: push 'start' synchronously; schedule setTimeout(..., 0) pushing 'timeout'; schedule Promise.resolve().then(...) pushing 'promise'; push 'end' synchronously; resolve (with the array) once the timeout has fired. Also write asyncOrder(): an async function f(log) pushes 'f1', awaits null, then pushes 'f2'; asyncOrder pushes 'before', calls f, pushes 'after', waits for f to finish and returns the log array.
