Implement structural binary tree algorithms on nodes shaped `{ val, left, right }`:

### `diameterOfBinaryTree(root)`
- Calculates the diameter of a binary tree, defined as the number of edges on the longest path between any two nodes.
- The path does not need to pass through the root.
- Returns `0` if `root` is `null` or consists of a single node.

### `isBalanced(root)`
- Determines whether the tree is height-balanced (for every node, left and right subtree heights differ by at most 1).
- Operates in a single O(n) bottom-up pass.
- Returns `true` for a balanced tree (or empty tree); returns `false` otherwise.

### `isSymmetric(root)`
- Checks whether the tree is symmetric around its center (a mirror image of itself).
- Returns `true` if symmetric (or if `root` is `null`); returns `false` otherwise.
