Tree nodes are { val, left, right } (null for a missing child).

Write diameterOfBinaryTree(root): the number of EDGES on the longest path between any two nodes (the path need not pass through the root; 0 for null or one node).

Write isBalanced(root): true when at every node the left and right heights differ by at most 1, in a single O(n) pass.

Write isSymmetric(root): true when the tree is a mirror image of itself (null is symmetric).
