Implement a custom hook useFetch(url) returning { data, loading, error } — initially { data: null, loading: true, error: null }; on success { data, loading: false, error: null }; on a non-2xx status or network failure { data: null, loading: false, error } where error is an Error (mentioning the status for HTTP errors). Use an AbortController inside useEffect to cancel the request if the url changes or the component unmounts, and never set state from an aborted/stale request.
