Build a component that auto-focuses on initial mount:

### FocusInput({ placeholder, label }: FocusInputProps): JSX.Element:
- Renders a `<label>` with the text `label` wrapping an `<input placeholder={placeholder}>`.
- Focuses that input when the component first mounts (use `useRef` and `useEffect`).
- Must not steal focus again on later re-renders.
