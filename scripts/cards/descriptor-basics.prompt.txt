Use Object.defineProperty.

Write defineHidden(obj, key, value): adds a property that is writable and configurable but NOT enumerable (it must not show up in Object.keys or JSON.stringify) and returns obj.

Write defineConstant(obj, key, value): adds an enumerable property that cannot be changed or deleted (not writable, not configurable) and returns obj.

Write describeFlags(obj, key): undefined if obj has no OWN property key; otherwise { writable, enumerable, configurable } for a data property, or { enumerable, configurable, accessor: true } for a getter/setter property.
