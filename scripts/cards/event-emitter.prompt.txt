Build an EventEmitter with on(event, fn), off(event, fn), once(event, fn) and emit(event, ...args). Listeners fire in registration order and receive all emitted arguments; emitting an event with no listeners does nothing. once() listeners run a single time, and off() can remove a once() listener before it fires. Removing a listener during emit must not skip the others, and the TypeScript version types payloads by event name.
