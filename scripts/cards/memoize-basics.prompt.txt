Implement function memoization helpers for single-argument functions:

### `memoizeOne(fn)`
- Returns a wrapped function that caches results in a `Map` keyed by the single argument.
- `fn` executes at most once per distinct argument value.
- Cache hits correctly return cached values even if the result is `undefined`, `null`, or other falsy values.
- Preserves `this` context when calling `fn`.

### `memoizeLast(fn)`
- Returns a wrapped function that caches only the single most recent argument and its result.
- If invoked with the same argument as the previous call (compared via `Object.is`), returns the cached result without invoking `fn`.
- When called with a new argument, re-executes `fn`, updates the cache, and returns the new result.
