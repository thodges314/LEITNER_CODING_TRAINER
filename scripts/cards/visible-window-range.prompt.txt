Calculate visible row ranges and offsets for a fixed-height virtualized list:

### getVisibleRange({ scrollTop, itemHeight, viewportHeight, itemCount, overscan = 0 }: { scrollTop: number; itemHeight: number; viewportHeight: number; itemCount: number; overscan?: number }): { start: number; end: number; offsetTop: number; totalHeight: number }:
- Returns `{ start, end, offsetTop, totalHeight }`.

#### Boundary & Scroll Clamping
- Computes `totalHeight = itemCount * itemHeight`.
- Computes `maxScroll = Math.max(0, totalHeight - viewportHeight)`.
- Clamps `scrollTop` between `0` and `maxScroll`.
- Edge case: if `itemCount === 0`, returns `{ start: 0, end: 0, offsetTop: 0, totalHeight: 0 }`.

#### Range Windowing Calculations
- **Visible Slice**:
  - `first = Math.floor(clampedScrollTop / itemHeight)`.
  - `last = Math.ceil((clampedScrollTop + viewportHeight) / itemHeight)` (partially visible rows count as visible).
- **Overscan Buffering**:
  - `start = Math.max(0, first - overscan)`.
  - `end = Math.min(itemCount, last + overscan)`.
- **Vertical Offset**:
  - `offsetTop = start * itemHeight`.
