Write createStorage(backend, { prefix = 'app:', now = Date.now } = {}) wrapping a localStorage-like backend (getItem, setItem, removeItem, key(i), length). set(key, value, { ttlMs }) stores JSON (returns true, or false if the backend throws, e.g. quota exceeded); get(key, fallback = null) returns the stored value, or the fallback when the key is missing, expired (also remove it) or the stored text is corrupt JSON (also remove it); remove(key); keys() lists this namespace's keys without the prefix; clear() removes only keys with this prefix.
