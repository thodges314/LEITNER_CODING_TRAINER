### `Skeleton({ variant = 'text', width, height, lines = 1, className = '', ...props }: SkeletonProps): JSX.Element`

## Description

```ts
type SkeletonVariant = 'text' | 'circular' | 'rectangular' | 'card';

interface SkeletonProps {
  variant?: SkeletonVariant;
  width?: string | number;
  height?: string | number;
  lines?: number;
  className?: string;
  [key: string]: any;
}
```

Skeleton screens provide visual feedback during asynchronous data fetching, eliminating cumulative layout shifts (CLS) and lowering perceived loading times.

Build an accessible, versatile skeleton loader React component styled with Tailwind CSS utility classes:

### Requirements

- **Accessibility Attributes**:
  - The outer container element must declare `role="status"`, `aria-label="Loading..."`, and `aria-busy="true"`.

- **Base Animation & Tone**:
  - All skeleton shapes use Tailwind's pulsing animation and a neutral muted background fill.

- **Variant Shapes**:
  - `'text'` (default):
    - When `lines === 1`: a single rounded text-height bar.
    - When `lines > 1`: a vertically spaced container holding `lines` rounded text bars where earlier lines span full width and the final line is shortened (~75–80% width) for realistic paragraph flow.
  - `'circular'`:
    - Non-shrinking circle defaulting to `2.5rem` (`10` spacing units) width and height when `width` and `height` are omitted.
  - `'rectangular'`:
    - Large rounded rectangle defaulting to full width and `8rem` (`32` spacing units) height when `width` and `height` are omitted.
  - `'card'`:
    - Composite card container with padding, rounded corners, subtle border, surface background, and vertical spacing:
      - Header row: circular avatar skeleton alongside stacked title and subtitle bars.
      - Media placeholder: full-width rounded block.
      - Content body bars: two stacked text lines (full width and shortened final line).

- **Dimension Handling & Props**:
  - If `width` or `height` is passed as a number, convert it to pixel dimensions in inline `style` (e.g. `width: 80` becomes `style={{ width: '80px' }}`).
  - If passed as a string, pass directly to inline `style` (e.g. `width: '50%'`).
  - Safely merges `className` with variant classes without clobbering.
  - Forwards extra props (`...props`) to the outer container element.
