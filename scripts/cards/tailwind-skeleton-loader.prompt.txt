### `Skeleton({ variant = 'text', width, height, lines = 1, className = '', ...props }: SkeletonProps): JSX.Element`

## Description

```ts
type SkeletonVariant = 'text' | 'circular' | 'rectangular' | 'card';

interface SkeletonProps {
  variant?: SkeletonVariant;
  width?: string | number;
  height?: string | number;
  lines?: number;
  className?: string;
  [key: string]: any;
}
```

Skeleton screens provide visual feedback during asynchronous data fetching, eliminating cumulative layout shifts (CLS) and lowering perceived loading times.

Build an accessible, versatile skeleton loader React component styled with Tailwind CSS utility classes:

### Requirements

- **Accessibility Attributes**:
  - The outer container element must declare `role="status"`, `aria-label="Loading..."`, and `aria-busy="true"`.

- **Base Animation & Tone**:
  - Base classes for all skeleton shapes: `animate-pulse bg-slate-800`.

- **Variant Shapes**:
  - `'text'` (default):
    - When `lines === 1`: A single bar with `h-4 rounded-md`.
    - When `lines > 1`: Renders a container (`space-y-2.5`) holding `lines` bars. Each bar is `h-4 rounded-md`. Earlier lines have `w-full`, while the final line has `w-4/5` (80% width) for realistic paragraph flow.
  - `'circular'`:
    - Classes: `rounded-full shrink-0`.
    - Default size: `h-10 w-10` when `width` and `height` are omitted.
  - `'rectangular'`:
    - Classes: `rounded-xl`.
    - Default size: `h-32 w-full` when `width` and `height` are omitted.
  - `'card'`:
    - Composite card layout container: `p-5 rounded-2xl border border-slate-800 bg-slate-900/50 space-y-4`.
    - Header row (`flex items-center gap-3`):
      - Circular avatar skeleton: `h-10 w-10 rounded-full shrink-0`.
      - Stacked title and subtitle bars (`space-y-1.5 flex-1`): title `h-3.5 w-28 rounded-md` and subtitle `h-2.5 w-20 rounded-md`.
    - Media placeholder: `h-28 w-full rounded-xl`.
    - Content body bars (`space-y-2`): two text lines, first `h-3 w-full rounded-md` and second `h-3 w-3/4 rounded-md`.

- **Dimension Handling & Props**:
  - If `width` or `height` is passed as a number, convert it to pixel dimensions in inline `style` (e.g. `width: 80` becomes `style={{ width: '80px' }}`).
  - If passed as a string, pass directly to inline `style` (e.g. `width: '50%'`).
  - Safely merges `className` with variant classes without clobbering.
  - Forwards extra props (`...props`) to the outer container element.
