### `Skeleton({ variant = 'text', width, height, lines = 1, className = '', ...props }: SkeletonProps): JSX.Element`

## Description

```ts
type SkeletonVariant = 'text' | 'circular' | 'rectangular' | 'card';

interface SkeletonProps {
  variant?: SkeletonVariant;
  width?: string | number;
  height?: string | number;
  lines?: number;
  className?: string;
  [key: string]: any;
}
```

Skeleton screens provide visual feedback during asynchronous data fetching, eliminating cumulative layout shifts (CLS) and lowering perceived loading times.

Build an accessible, versatile skeleton loader React component styled with Tailwind CSS utility classes:

### Requirements

- **Accessibility Attributes**:
  - The outer container element must declare `role="status"`, `aria-label="Loading..."`, and `aria-busy="true"`.

- **Base Animation & Tone**:
  - All skeleton shapes use `animate-pulse` and a neutral muted background fill.

- **Variant Shapes**:
  - `'text'` (default):
    - When `lines === 1`: a single `h-4` rounded bar.
    - When `lines > 1`: a vertically spaced container (`space-y-2.5`) holding `lines` `h-4` rounded bars where earlier lines span full width (`w-full`) and the final line is shortened (`w-4/5`) for realistic paragraph flow.
  - `'circular'`:
    - Non-shrinking circle (`rounded-full shrink-0`) defaulting to `h-10 w-10` when `width` and `height` are omitted.
  - `'rectangular'`:
    - Large rounded rectangle (`rounded-xl`) defaulting to `h-32 w-full` when `width` and `height` are omitted.
  - `'card'`:
    - Composite card container with padding, rounded corners, subtle border, surface background, and vertical spacing (`space-y-4`):
      - Header row (`flex items-center gap-3`): `h-10 w-10` circular avatar skeleton alongside stacked title and subtitle bars (`flex-1`).
      - Media placeholder: `h-28 w-full` rounded block.
      - Content body bars: two stacked text lines (`w-full` and `w-3/4`).

- **Dimension Handling & Props**:
  - If `width` or `height` is passed as a number, convert it to pixel dimensions in inline `style` (e.g. `width: 80` becomes `style={{ width: '80px' }}`).
  - If passed as a string, pass directly to inline `style` (e.g. `width: '50%'`).
  - Safely merges `className` with variant classes without clobbering.
  - Forwards extra props (`...props`) to the outer container element.
