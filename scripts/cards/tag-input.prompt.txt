Build TagInput({ value, onChange, max = Infinity }) as a controlled component where value is an array of strings. Render <ul aria-label="Tags"> with one <li> per tag containing the tag text and <button type="button" aria-label="Remove <tag>">, followed by <input aria-label="Add tag"> (its text is local state). Pressing Enter or ',' adds the trimmed text as a new tag via onChange([...value, tag]) and clears the input (and prevents the key's default). Empty text and duplicates (case-insensitive) are ignored (the input is cleared for a duplicate), and nothing is added once value.length >= max. Backspace in an EMPTY input removes the last tag. The Remove button removes that tag.
