### delegate(root: HTMLElement, selector: string, eventType: string, handler: (this: Element, event: Event, matchedElement: Element) => void): () => void
Write `delegate(root, selector, eventType, handler)` that attaches ONE listener to `root` and calls `handler(event, matchedElement)` (with `this` also set to the matched element) when the event originated at or inside an element matching `selector`. Use the nearest match (`Element.closest`), ignore matches that are outside `root` or the root itself, support elements added after the call, and return a function that removes the listener.
