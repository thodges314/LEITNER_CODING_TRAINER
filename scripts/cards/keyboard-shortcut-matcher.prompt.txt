Write three functions for keyboard shortcuts. parseShortcut(text) turns a string like 'Ctrl+Shift+K' into { key, ctrl, meta, alt, shift, mod }: split on '+', ignore spaces and case, lowercase the key, and map the aliases control -> ctrl, cmd and command -> meta, option -> alt, esc -> escape, return -> enter, space -> ' ' ('mod' is its own flag). matchesShortcut(event, shortcut, isMac = false) takes a keyboard-event-like object { key, ctrlKey, metaKey, altKey, shiftKey } and returns true only when the key matches (case-insensitive) AND the modifiers match exactly: a missing or an extra modifier means no match. 'mod' means Cmd on a Mac (isMac true) and Ctrl everywhere else. findShortcut(event, bindings, isMac = false) takes an object of { name: shortcut } and returns the name of the first binding that matches, or null.
