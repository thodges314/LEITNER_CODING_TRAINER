Implement side-channel metadata and visited-tracking utilities using module-level `WeakMap` and `WeakSet` (without modifying or adding properties to the target objects themselves):

### `tag(obj, label)`
- Associates a metadata `label` with `obj` using a `WeakMap`.
- Returns `obj`.

### `getTag(obj)`
- Returns the stored `label` associated with `obj`, or `undefined` if untagged.

### `untag(obj)`
- Removes the tag association from the `WeakMap`.
- Returns `true` if a tag was removed, or `false` otherwise.

### `markSeen(obj)`
- Uses a `WeakSet` to track visited objects.
- Returns `true` the very first time an object is encountered.
- Returns `false` for any subsequent call with the same object.
