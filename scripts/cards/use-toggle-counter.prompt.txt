```ts
interface CounterOptions {
  initial?: number;
  min?: number;
  max?: number;
  step?: number;
}

interface CounterResult {
  count: number;
  increment: () => void;
  decrement: () => void;
  reset: () => void;
  set: (n: number) => void;
}
```

Implement two custom utility hooks: `useToggle` and `useCounter`.

### useToggle(initial: boolean = false): [boolean, () => void, (next: boolean) => void]:
- **Returns**: `[value, toggle, setValue]`.
- `toggle()`: Flips `value`. It must ignore any passed arguments (e.g. an `onClick` event) and maintain a stable function identity across renders.
- `setValue(next)`: Directly sets `value` to `next` (boolean).

### useCounter({ initial = 0, min = -Infinity, max = Infinity, step = 1 }: CounterOptions = {}): CounterResult:
- **Returns**: `CounterResult` containing `{ count, increment, decrement, reset, set }`.
- **Clamping**: All operations clamp `count` to `[min, max]`, including the initial value, `increment()`, `decrement()`, and `set(n)`.
- **Operations**:
  - `increment()`: Moves `count` up by `step` (clamped to `max`).
  - `decrement()`: Moves `count` down by `step` (clamped to `min`).
  - `reset()`: Restores `count` to the (clamped) initial value.
  - `set(n)`: Sets `count` to `n` (clamped to `[min, max]`).
- **Identity**: Returned helper functions maintain stable identities across renders while their options do not change.
