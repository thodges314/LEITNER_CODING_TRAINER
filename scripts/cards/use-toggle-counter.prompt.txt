Write useToggle(initial = false) returning [value, toggle, setValue]: toggle() flips the value (it must ignore any arguments, e.g. a click event) and has a stable identity across renders.

Write useCounter({ initial = 0, min = -Infinity, max = Infinity, step = 1 } = {}) returning { count, increment, decrement, reset, set }: increment/decrement move by `step`, everything is clamped to [min, max] (including the initial value and set(n)), reset returns to the (clamped) initial value, and the functions keep a stable identity while their options do not change.
