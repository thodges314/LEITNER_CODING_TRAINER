Implement a First-In-First-Out (FIFO) in-memory cache class:

### `FifoCache(capacity)`

- **`get size`**:
  - Getter returning the current number of cached entries.
- **`get(key)`**:
  - Returns the cached value for `key`, or `undefined` if not found.
  - Does not modify insertion order.
- **`set(key, value)`**:
  - If `key` already exists, updates its value without resetting its insertion order/age.
  - If `key` is new:
    - If `size >= capacity`, evicts the oldest inserted key before storing the new entry.
    - Stores the new `key` and `value`.
