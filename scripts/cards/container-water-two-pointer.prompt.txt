Implement two classic geometric two-pointer algorithms in $O(n)$ time and $O(1)$ space:

### `maxArea(heights: number[]): number`
Given an array `heights` where each element represents a vertical line at index $i$ with height $h_i$ (from $(i, 0)$ to $(i, h_i)$), find two lines that together with the x-axis form a container holding the **most water**.
- The water held between indices $i < j$ is bounded by the shorter wall:

$$A(i, j) = (j - i) \cdot \min(h_i, h_j)$$

- **Two-Pointer Intuition**: Start with `left = 0` and `right = heights.length - 1`. At each step, moving the *taller* wall inward can only shrink width without increasing the limiting height, so always move the *shorter* wall inward.
- **Example**: `maxArea([1, 8, 6, 2, 5, 4, 8, 3, 7])` returns `49` (using index `1` with height `8` and index `8` with height `7`: width $8 - 1 = 7$, height $\min(8, 7) = 7$, area $7 \times 7 = 49$).
- **Edge Case**: Returns `0` if `heights.length < 2`.

### `trap(height: number[]): number`
Given an elevation map where each bar has width `1` and height `height[i]`, compute the **total units of rainwater** trapped between the bars after raining.
- Water above index $i$ equals the difference between the shorter of the tallest walls to its left ($L_i$) and right ($R_i$) and its own height:

$$V = \sum_{i=0}^{n-1} \max\!\Bigl(0,\; \min(L_i, R_i) - h_i\Bigr)$$

- **Two-Pointer Intuition**: Maintain `left`, `right`, `leftMax`, and `rightMax`. Whichever side has the smaller max wall determines the trapped water at that pointer immediately, because the opposite side is guaranteed to have a wall at least as tall.
- **Example**: `trap([0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1])` returns `6` (water fills the dips at indices `2`, `4`, `5`, `6`, and `9`).
- **Edge Case**: Returns `0` if `height.length < 3`.
