Implement two classic geometric array algorithms in $O(n)$ time and $O(1)$ space:

### `maxArea(heights: number[]): number`
Given an array `heights` where each element represents a vertical line at index $i$ with height $h_i$ (from $(i, 0)$ to $(i, h_i)$), find two lines that together with the x-axis form a container holding the **most water**:

$$A(i, j) = (j - i) \cdot \min(h_i, h_j)$$

- **Example**: `maxArea([1, 8, 6, 2, 5, 4, 8, 3, 7])` returns `49` (using index `1` with height `8` and index `8` with height `7`: width $8 - 1 = 7$, height $\min(8, 7) = 7$, area $7 \times 7 = 49$).
- **Edge Case**: Returns `0` if `heights.length < 2`.

### `trap(height: number[]): number`
Given an elevation map where each bar has width `1` and height `height[i]`, compute the **total units of rainwater** trapped between the bars after raining (where $L_i$ and $R_i$ are the tallest bars to the left and right of index $i$):

$$V = \sum_{i=0}^{n-1} \max\!\Bigl(0,\; \min(L_i, R_i) - h_i\Bigr)$$

- **Example**: `trap([0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1])` returns `6` (water fills the dips at indices `2`, `4`, `5`, `6`, and `9`).
- **Edge Case**: Returns `0` if `height.length < 3`.
