Write singleNumber(nums): every number appears twice except one; return that one using XOR (O(1) extra space). Write countOneBits(n): the number of 1 bits in the binary form of a non-negative integer up to 2^32 - 1 (use n & (n - 1) to clear the lowest set bit; countOneBits(0) is 0). Write isPowerOfTwo(n): true for 1, 2, 4, 8, ... and false for 0 and negative numbers, using a bitwise test (no loops, no Math.log).
