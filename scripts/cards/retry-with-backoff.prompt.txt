Implement `retry(fn, options)` for an async function `fn`:

### `retry<T>(fn: (attempt: number) => Promise<T>, options?: RetryOptions): Promise<T>`
- **Options**: `{ retries = 3, baseDelay = 20, factor = 2, signal?: AbortSignal }`.
- **Execution Limits**: Invokes `fn` at most `retries + 1` times (1 initial attempt + `retries` retry attempts).
- **Exponential Backoff**: Waits `baseDelay * (factor ** n)` ms before attempt `n + 1` (e.g. `baseDelay`, then `baseDelay * factor`, etc.).
- **Resolution & Rejection**:
  - Resolves immediately with the first successful result.
  - If all attempts fail, rejects with the error thrown on the final attempt.
- **`AbortSignal` Support**:
  - If `signal` is already aborted on entry, rejects immediately without calling `fn`.
  - If `signal` aborts during a backoff delay, terminates waiting immediately and rejects with the signal's abort reason (`AbortError`).
