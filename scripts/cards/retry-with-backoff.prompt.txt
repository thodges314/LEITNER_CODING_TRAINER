Implement retry(fn, { retries = 3, baseDelay = 20, factor = 2, signal }) for an async fn. It calls fn at most retries + 1 times (1 initial attempt + `retries` retries). Wait baseDelay * factor^n ms before retry n+1 (baseDelay, then baseDelay * factor, ...). Resolve with the first successful result; if every attempt fails, reject with the last error. If the AbortSignal is already aborted, reject without calling fn; if it aborts during a backoff wait, stop waiting immediately and reject with the abort reason (an AbortError).
