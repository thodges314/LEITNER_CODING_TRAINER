Implement TypeScript narrowing using `typeof`, `Array.isArray`, and `in`:

### `describe(value: string | number | string[]): string`
- Returns `'string:<length>'` for a string.
- Returns `'number:<value with one decimal, via toFixed(1)>'` for a number.
- Returns `'list:<length>'` for an array.
- Narrows using `typeof` and `Array.isArray`.

### `type Shape`
- Defined as `{ radius: number } | { width: number; height: number }`.

### `area(shape: Shape): number`
- Narrows `shape` using the `in` operator.
- Circle: returns `Math.PI * radius ** 2` rounded to 2 decimals (`Math.round(Math.PI * shape.radius ** 2 * 100) / 100`).
- Rectangle: returns `width * height`.
