Implement a lightweight publish-subscribe callback emitter:

### `createEmitter()`
Returns an emitter object with the following methods:

- **`on(event, fn)`**:
  - Registers a listener function `fn` for the string `event`.
  - Multiple listeners for the same event are preserved and invoked in registration order.
- **`emit(event, ...args)`**:
  - Invokes all registered listeners for `event` with `...args`.
  - Returns the total count of listeners called (returns `0` if none).
  - Emitting an event without listeners does not throw.
