### `Button({ variant = 'primary', size = 'md', loading = false, disabled = false, children, onClick, ...props }: ButtonProps): JSX.Element`

## Description

```ts
type ButtonVariant = 'primary' | 'secondary' | 'destructive' | 'outline';
type ButtonSize = 'sm' | 'md' | 'lg';

interface ButtonProps {
  variant?: ButtonVariant;
  size?: ButtonSize;
  loading?: boolean;
  disabled?: boolean;
  children?: any;
  onClick?: (event: any) => void;
  [key: string]: any;
}
```

Interactive, accessible buttons with cohesive hover, focus-visible rings, press transitions, and asynchronous loading states form the bedrock of any component library.

Build an accessible, versatile React button styled with Tailwind CSS utility classes:

### Requirements

- **Base Layout & Pseudo-States** (`<button>`):
  - Elements: `<button type="button" ...>` (defaults to `type="button"` unless specified in `props`).
  - Layout & interactive base utilities: inline-flex centered alignment, medium font weight, smooth transitions, `focus-visible` outline removal with a 2px ring and offset, active press scale-down, and pointer cursor.
  - Forwards extra props (such as `aria-label`, `data-testid`, or `id`) to the underlying `<button>`.

- **Variant Styling**:
  - `'primary'` (default): indigo/blue solid background with white text, lighter hover state, and matching `focus-visible` ring.
  - `'secondary'`: dark slate/neutral background with light text, lighter hover state, and slate `focus-visible` ring.
  - `'destructive'`: rose/red solid background with white text, lighter hover state, and matching `focus-visible` ring.
  - `'outline'`: bordered button using midtone slate border/text, translucent hover fill, and slate `focus-visible` ring.

- **Sizes & Spacing**:
  - `'sm'`: extra-small text, compact padding, rounded corners, and small flex gap.
  - `'md'` (default): small text, standard padding, larger rounded corners, and medium flex gap.
  - `'lg'`: base text, generous padding, larger rounded corners, and wider flex gap.

- **Disabled State**:
  - When `disabled` is `true` or `loading` is `true`:
    - Disables the `<button>` element via its `disabled` attribute.
    - Includes Tailwind disabled utilities for reduced opacity, disabled pointer events, and a not-allowed cursor.

- **Loading State**:
  - When `loading` is `true`:
    - Sets `aria-busy="true"` on the `<button>`.
    - Renders an animated spinning inline `<svg>` indicator before `children`.
