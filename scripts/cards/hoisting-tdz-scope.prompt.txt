Write hoistingBehavior(): returns an object { varBefore: undefined, fnResult: 'hoisted' } demonstrating that var declarations are hoisted and initialized to undefined, and function declarations are hoisted with their body.

Write checkTDZ(fn): runs fn(); if accessing a variable before initialization throws a ReferenceError, returns 'ReferenceError'; if it runs cleanly, returns 'ok'; for any other error, returns 'error'.

Write makeLoopCallbacksVar(n): returns an array of n zero-argument functions created in a var loop for (var i = 0; i < n; i++) { ... }, where calling any function returns the final shared value n.

Write makeLoopCallbacksLet(n): returns an array of n functions created in a let loop for (let i = 0; i < n; i++) { ... }, where calling fn[k]() returns k.
