Build an accessible tooltip component:

### Tooltip({ content, children }: TooltipProps): JSX.Element:
- `children` is a single React element (typically a `<button>`).
- **Trigger Cloning**: Use `React.cloneElement` on `children` to attach event handlers while preserving all original child props and existing handlers (`onMouseEnter`, `onMouseLeave`, `onFocus`, `onBlur`, `onKeyDown`).
- **Visibility Triggers**:
  - **Show**: On mouse enter (`mouseenter`) and on keyboard focus (`focus`).
  - **Hide**: On mouse leave (`mouseleave`), on blur (`blur`), or when `Escape` is pressed.
- **Accessibility & ARIA**:
  - While visible, render `<span role="tooltip" id={id}>{content}</span>` next to the trigger (`content` may be any React node) and set `aria-describedby={id}` on the trigger element.
  - While hidden, render no tooltip element and omit `aria-describedby` from the trigger.
  - Generate `id` using React's `useId()`.
