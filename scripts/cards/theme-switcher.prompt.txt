Build ThemeProvider({ children, storageKey = "demo-color-scheme", defaultTheme = "light" }) and the hook useTheme() returning { theme, setTheme, toggle }. The only valid themes are "light" and "dark". The initial theme is the value saved in localStorage under storageKey when it is valid, otherwise defaultTheme (an invalid saved value such as "blue" is ignored). Whenever the theme changes, set the data-color-scheme attribute on document.documentElement and save the theme to localStorage[storageKey] (use an effect). toggle() flips light <-> dark; setTheme(next) switches to next but ignores anything that is not "light" or "dark". useTheme() called outside a ThemeProvider must throw an Error whose message mentions "ThemeProvider". (The attribute is data-color-scheme and the default key is "demo-color-scheme" on purpose, so this exercise never touches the app's own theme.)
