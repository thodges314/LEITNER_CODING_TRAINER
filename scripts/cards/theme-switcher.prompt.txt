Build a persistent Theme Context provider and hook using `localStorage`:

### ThemeProvider({ children, storageKey = 'demo-color-scheme', defaultTheme = 'light' }: { children: React.ReactNode; storageKey?: string; defaultTheme?: 'light' | 'dark' }): JSX.Element:
- Allowed themes: `'light'` and `'dark'`.
- **Initialization**:
  - Reads `localStorage.getItem(storageKey)` during state initialization.
  - If the stored value is `'light'` or `'dark'`, uses it; otherwise falls back to `defaultTheme` (invalid values like `'blue'` are ignored).
- **DOM & Storage Sync**:
  - In a `useEffect`, updates whenever `theme` or `storageKey` changes:
    - Sets `document.documentElement.setAttribute('data-color-scheme', theme)`.
    - Saves `localStorage.setItem(storageKey, theme)`.
- **Context Methods**:
  - `toggle()`: flips between `'light'` and `'dark'`.
  - `setTheme(next)`: updates to `next` if it is `'light'` or `'dark'` (ignores any invalid theme string).

### useTheme(): { theme: 'light' | 'dark'; setTheme: (next: 'light' | 'dark') => void; toggle: () => void }:
- Custom hook that consumes the theme context.
- Returns `{ theme, setTheme, toggle }`.
- Throws an `Error` whose message mentions `'ThemeProvider'` when called outside a `<ThemeProvider>`.
