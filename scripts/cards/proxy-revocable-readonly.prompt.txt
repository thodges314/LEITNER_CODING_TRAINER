Write createReadOnly(obj) returning { proxy, revoke } built with Proxy.revocable. Through proxy: reads work and always reflect the live source object; set, defineProperty and deleteProperty throw TypeError('Read-only'); any property whose value is an object is returned wrapped in its own read-only proxy (so nested writes throw too, deeply). Calling revoke() must revoke the top-level proxy AND every nested proxy created so far, after which any access throws a TypeError (message contains 'revoked').
