Implement generic TypeScript helper functions and container types without using `any`:

### `identity<T>(value: T): T`
- Returns the provided value unchanged with its exact type preserved.

### `first<T>(items: T[]): T | undefined`
- Returns the first element of `items`, or `undefined` if the array is empty.

### `Box<T>` & Box Helpers
- **`interface Box<T>`**: `{ value: T }`
- **`makeBox<T>(value: T): Box<T>`**: wraps `value` inside a `{ value }` container.
- **`mapBox<T, U>(box: Box<T>, fn: (value: T) => U): Box<U>`**: transforms `box.value` using `fn` and returns a new `Box<U>`.
