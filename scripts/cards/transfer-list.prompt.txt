```ts
interface TransferListResult {
  left: string[];
  right: string[];
  leftSelected: string[];
  rightSelected: string[];
  toggleLeft: (item: string) => void;
  toggleRight: (item: string) => void;
  moveRight: () => void;
  moveLeft: () => void;
  moveAllRight: () => void;
  moveAllLeft: () => void;
}
```

### useTransferList({ initialLeft = [], initialRight = [] }: { initialLeft?: string[]; initialRight?: string[] } = {}): TransferListResult:

Implement a dual-column selection manager hook `useTransferList`.

- **State**: Maintains items in `left` and `right` string arrays, along with `leftSelected` and `rightSelected` arrays.
- **Selection**:
  - `toggleLeft(item)`: toggles selection of `item` in `leftSelected`.
  - `toggleRight(item)`: toggles selection of `item` in `rightSelected`.
- **Transfer Operations**:
  - `moveRight()`: moves all items currently in `leftSelected` from `left` to `right`, and clears `leftSelected`.
  - `moveLeft()`: moves all items currently in `rightSelected` from `right` to `left`, and clears `rightSelected`.
  - `moveAllRight()`: moves all items from `left` to `right`, clearing `left` and `leftSelected`.
  - `moveAllLeft()`: moves all items from `right` to `left`, clearing `right` and `rightSelected`.
- **Return Value**: Returns `TransferListResult` containing `{ left, right, leftSelected, rightSelected, toggleLeft, toggleRight, moveRight, moveLeft, moveAllRight, moveAllLeft }`.
