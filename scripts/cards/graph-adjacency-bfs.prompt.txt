Implement fundamental undirected graph representation and search algorithms from an edge list of `[a, b]` pairs:

### `buildGraph<T extends string | number>(edges: [T, T][]): Record<T, T[]>`
- Constructs an undirected adjacency list object mapping each node to an array of its neighbors.
- Neighbors are ordered as the edges appear in `edges`.
- For example, `buildGraph([[1, 2], [1, 3]])` returns `{ 1: [2, 3], 2: [1], 3: [1] }`.
- Returns `{}` when `edges` is empty (`[]`).

### `hasPath<T extends string | number>(edges: [T, T][], start: T, end: T): boolean`
- Returns `true` if a path exists from node `start` to `end`; `false` otherwise.
- A node is always considered to reach itself (`start === end` returns `true`).

### `shortestPathLength<T extends string | number>(edges: [T, T][], start: T, end: T): number`
- Uses Breadth-First Search (BFS) to find the minimum number of edges on a path connecting `start` and `end`.
- Returns `0` if `start === end`, and `-1` if `end` is unreachable from `start`.
