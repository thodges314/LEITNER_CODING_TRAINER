An undirected graph is given as an array of [a, b] edges. Write buildGraph(edges) returning an object that maps each node to an array of its neighbours in the order the edges appear (buildGraph([[1, 2], [1, 3]]) is { 1: [2, 3], 2: [1], 3: [1] }), hasPath(edges, start, end) returning true when end can be reached from start (a node always reaches itself), and shortestPathLength(edges, start, end) using breadth-first search that returns the minimum number of edges, or -1 when unreachable.
