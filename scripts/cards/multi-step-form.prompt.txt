```ts
interface FormFieldDef {
  name: string;
  label: string;
}

interface StepDef {
  title: string;
  fields: FormFieldDef[];
}
```

Build a multi-step form wizard component:

### Wizard({ steps, onSubmit }: { steps: StepDef[]; onSubmit: (values: Record<string, string>) => void }): JSX.Element:
- Render one `<form>` displaying `<p>Step X of N</p>`, an `<h2>` with the step title, and for each field a `<label>` wrapping a controlled `<input name>`.
- Controls: Provide `<button type="button">Back</button>` (disabled on the first step) and `<button type="submit">` labelled `'Next'` (or `'Submit'` on the last step).
- **Validation**: Submitting the form (via `Enter` or the submit button) validates the **CURRENT** step only:
  - If any of its fields is empty after trimming, show `<p role="alert">All fields are required</p>` and stay on the current step.
  - Otherwise, advance to the next step, or on the final step call `onSubmit(values)` with **ALL** values entered across all steps.
- **Persistence**: Values entered in earlier steps must be preserved when navigating `Back` and `Next`. Moving between steps clears the alert message.
