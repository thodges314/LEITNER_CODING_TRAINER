Build a Zustand-style external store and subscription hook:

### createStore<T extends Record<string, unknown>>(initialState: T): ExternalStore<T>
- Returns `{ getState, setState, subscribe }`.
- **`getState()`**: Returns the current state object.
- **`setState(partialOrUpdater)`**:
  - Accepts a partial object or updater function `(state) => patch`.
  - Merges into the next state: `{ ...state, ...patch }`.
  - Notifies subscribers **only** if at least one property changed (`!Object.is(next[k], state[k])`).
- **`subscribe(listener)`**:
  - Registers `listener` and returns an unsubscribe cleanup function.

### useStore<T extends Record<string, unknown>, S = T>(store: ExternalStore<T>, selector?: (state: T) => S): S
- Custom React hook built using `useSyncExternalStore`.
- Subscribes via `store.subscribe` and reads state slice via `() => selector(store.getState())`.
- Component re-renders only when its selected slice changes, and automatically unsubscribes on unmount.
