Build a tiny Zustand-style store. createStore(initialState) returns { getState, setState, subscribe }: setState(partialOrUpdater) shallow-merges a partial object (or the result of an updater function receiving the current state) and notifies subscribers ONLY if some value actually changed (Object.is); subscribe(listener) returns an unsubscribe function. useStore(store, selector = (s) => s) is a hook built on useSyncExternalStore that returns the selected slice, so a component re-renders only when its slice changes, and unsubscribes on unmount.
