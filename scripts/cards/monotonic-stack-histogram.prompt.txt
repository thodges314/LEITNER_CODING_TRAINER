Write stockSpan(prices): for each day the number of consecutive days ending today (including today) whose price is <= today's price (stockSpan([100, 80, 60, 70]) is [1, 1, 1, 2]).

Write largestRectangleArea(heights): the area of the largest rectangle that fits inside a histogram of bars with width 1 (0 for an empty histogram). Use a monotonic stack so that both run in O(n).
