Implement subsequence comparison algorithms:

### `longestCommonSubsequence(a, b)`
- Computes the length of the longest common subsequence present in both strings `a` and `b` using a 2D dynamic programming table.
- Subsequence characters must appear in the same relative order, but need not be contiguous.
- Returns `0` if either string is empty.

### `isSubsequence(s, t)`
- Determines whether string `s` is a subsequence of string `t` using a two-pointer approach in O(length of t) time.
- Returns `true` if `s` is the empty string `""`.
