Define a generic component prop interface and rendering function where TypeScript enforces type parity across items and value:

### `SelectProps<T>`
Interface with the following properties:
- `items: T[]` — array of options.
- `value: T` — currently selected option of the same type `T`.
- `onChange: (item: T) => void` — callback invoked with an item of type `T`.
- `getLabel: (item: T) => string` — returns the display string for an item.

### `renderSelect<T>(props: SelectProps<T>): string`
- Maps each element in `props.items` through `props.getLabel(item)`.
- Joins the labels with `', '` (returns `''` when `items` is empty).
- Enforces at compile-time that `items` and `value` share the exact same type `T`.
