Write floodFill(image, sr, sc, color): replace the 4-directionally connected region of equal values that contains (sr, sc) with color and return the image (if the start cell already has color, change nothing).

Write numIslands(grid): the number of 4-directionally connected groups of '1' cells in a grid of '0'/'1' strings (an empty grid has 0). numIslands must not mutate the caller's grid.
