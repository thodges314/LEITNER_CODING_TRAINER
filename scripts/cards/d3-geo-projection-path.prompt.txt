### `renderGeoMap(container: HTMLElement, geojson: GeoFeatureCollection, options?: GeoMapOptions): GeoMapInstance`

## Description

```ts
interface GeoFeature {
  type: 'Feature';
  id?: string | number;
  properties?: {
    name?: string;
    [key: string]: any;
  };
  geometry: {
    type: string;
    coordinates: any;
  };
}

interface GeoFeatureCollection {
  type: 'FeatureCollection';
  features: GeoFeature[];
}

interface GeoCentroidMetric {
  id: string;
  name: string;
  x: number;
  y: number;
  area: number;
}

interface GeoMapOptions {
  width?: number;
  height?: number;
  projectionType?: 'mercator' | 'equirectangular' | 'orthographic';
  padding?: number;
  fillColor?: string;
  activeColor?: string;
  strokeColor?: string;
  showCentroids?: boolean;
  onSelectFeature?: (feature: GeoFeature, metric: GeoCentroidMetric, index: number) => void;
}

interface GeoMapInstance {
  svg: SVGSVGElement;
  projection: d3.GeoProjection;
  pathGenerator: d3.GeoPath;
  getCentroids: () => GeoCentroidMetric[];
  projectCoordinate: (lonLat: [number, number]) => [number, number] | null;
  destroy: () => void;
}
```

Cartographic visualizations project spherical longitude/latitude coordinates (`[lon, lat]`) onto a 2D planar SVG viewport using projections (`d3.geoMercator()`, `d3.geoEquirectangular()`, `d3.geoOrthographic()`) and path generators (`d3.geoPath(projection)`).

Implement `renderGeoMap(container, geojson, options)` to fit a GeoJSON `FeatureCollection` into a padded SVG viewport, render interactive region polygons and projected centroids, and expose coordinate projection utilities.

### Requirements

- **Canvas & Projection Setup**:
  - Empties `container.innerHTML` and appends an `<svg>` element with `width={width}`, `height={height}`, `role="img"`, and `aria-label="Geographic map"`.
  - Option defaults: `width = 480`, `height = 300`, `projectionType = 'mercator'`, `padding = 16`, `fillColor = '#1e293b'`, `activeColor = '#3b82f6'`, `strokeColor = '#64748b'`, `showCentroids = true`.
  - Selects the D3 projection based on `projectionType`:
    - `'equirectangular'` -> `d3.geoEquirectangular()`
    - `'orthographic'` -> `d3.geoOrthographic()`
    - `'mercator'` (default) -> `d3.geoMercator()`
  - When `geojson?.features` is non-empty, fits the projection to the padded viewport:
    `projection.fitExtent([[padding, padding], [Math.max(padding + 1, width - padding), Math.max(padding + 1, height - padding)]], geojson)`.
  - Creates `pathGenerator = d3.geoPath(projection)`.

- **Feature Polygons & Centroid Metrics**:
  - For each feature `(f, i)` in `geojson.features`, computes a `GeoCentroidMetric`:
    - `id = String(f.id ?? f.properties?.name ?? i)`
    - `name = String(f.properties?.name ?? f.id ?? 'Region ' + i)`
    - `[cx, cy] = pathGenerator.centroid(f)` (`x = Number.isFinite(cx) ? cx : 0`, `y = Number.isFinite(cy) ? cy : 0`)
    - `area = pathGenerator.area(f)` (`Number.isFinite(area) ? area : 0`)
  - Appends `<g class="map-features">` containing `<path class="geo-feature">` for each feature:
    - `d = pathGenerator(f) || ''`, `fill = fillColor`, `stroke = strokeColor`, `stroke-width = "1.25"`
    - `data-id = metric.id`, `data-name = metric.name`, `data-index = String(i)`, `data-active = "false"`
    - Clicking a `path.geo-feature` marks the clicked feature `data-active="true"` and `fill={activeColor}` (resetting other features to `data-active="false"` and `fill={fillColor}`) and calls `options.onSelectFeature(f, metric, i)` if provided.
  - Appends `<g class="map-centroids">`:
    - When `showCentroids !== false`, renders `<circle class="geo-centroid">` for each feature with `cx={metric.x}`, `cy={metric.y}`, `r="3.5"`, `fill={activeColor}`, and `data-id={metric.id}`.

- **Instance API**:
  - `getCentroids()`: returns the array of `GeoCentroidMetric` objects.
  - `projectCoordinate(lonLat)`: returns `projection(lonLat)`.
  - `destroy()`: removes the SVG and empties `container.innerHTML`.

#### Optional Styling (CSS is not graded)
Optional helper classes are available in the preview environment:
- `.geo-feature`: region polygon path element.
- `.geo-centroid`: region centroid marker circle.
You may use these classes, custom styles, or your own class names.
