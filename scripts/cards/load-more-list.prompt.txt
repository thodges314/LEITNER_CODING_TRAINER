Build LoadMoreList({ fetchPage }) where fetchPage(page) returns a Promise of { items: string[], hasMore: boolean } and pages start at 1. On mount load page 1. Render <ul> with one <li> per loaded item; while a request is in flight render <p role="status">Loading…</p>. When more pages exist and nothing is loading, show a <button>Load more</button> that loads the next page and APPENDS its items; ignore clicks while a request is in flight; hide the button after the last page. If a request fails render <p role="alert">Failed to load</p> and a <button>Retry</button> that re-requests the SAME page (no items are lost).
