Implement two recursive **backtracking** generators that produce every valid result in sorted order:

{{include:backtracking-explanation.md}}

### `binaryStrings(n: number): string[]`
Generates **every possible string of length `n` made only of `'0'` and `'1'`**, sorted in dictionary (alphabetical) order (`'0'` before `'1'`).
- **Examples**:
  - `binaryStrings(0)` $\to$ `['']`
  - `binaryStrings(2)` $\to$ `['00', '01', '10', '11']`
  - `binaryStrings(3)` $\to$ `['000', '001', '010', '011', '100', '101', '110', '111']` (total $2^n$ strings).

### `combine(n: number, k: number): number[][]`
Given two integers `n` and `k`, return **all unique groups of `k` numbers chosen from `1` through `n`** (order inside a group doesn't matter, so `[1, 2]` and `[2, 1]` are the same group — only include `[1, 2]`).
- **Ordering Rules**:
  - Each group is sorted in ascending order (e.g. `[1, 3]`, never `[3, 1]`).
  - The list of groups is returned in dictionary order: `combine(4, 2)` $\to$ `[[1, 2], [1, 3], [1, 4], [2, 3], [2, 4], [3, 4]]`.
- **Edge Cases**: Returns `[[]]` for `k === 0`; returns `[]` when `k > n`.
