Write the logic behind a drag-sortable list. dropIndex(pointerY, rects) takes the pointer's vertical position and an array of { top, height } rectangles (one per item, top to bottom) and returns the insertion index 0..rects.length: the position of the first item whose vertical midpoint is BELOW the pointer (a pointer exactly on a midpoint counts as past it), or rects.length when the pointer is below every midpoint. moveItem(list, from, to) returns a NEW array with the item at index `from` moved so that it sits in the gap `to` of the ORIGINAL list (gap 0 is before the first item, gap list.length after the last one). Moving an item into its own gap (to === from or to === from + 1) returns an unchanged copy. Never mutate the input. reorderOnDrop(list, from, pointerY, rects) combines the two.
