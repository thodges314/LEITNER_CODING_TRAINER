```ts
interface SimpleErrorBoundaryProps {
  fallback: React.ReactNode;
  onError?: (error: Error) => void;
  children: React.ReactNode;
}

interface SimpleErrorBoundaryState {
  failed: boolean;
}
```

Write `SimpleErrorBoundary` as a class component (in React, error boundaries must be class components):

### class SimpleErrorBoundary extends React.Component<SimpleErrorBoundaryProps, SimpleErrorBoundaryState>
- **Normal Render**:
  - Renders `children` normally when no error has occurred.
- **Error Handling**:
  - Catches render errors from any descendant component using `static getDerivedStateFromError()`.
  - Sets `{ failed: true }` in state and renders `fallback` instead of `children`.
  - Calls `onError(error)` once in `componentDidCatch(error)` with the caught error (if `onError` is provided).
- **Fault Isolation**:
  - A failure inside one boundary must not affect sibling boundaries or outside components.
