Write a promise pipeline using explicit chaining syntax (`.then()`, `.catch()`, `.finally()`) without `async`/`await`:

### `getUserData(url: string): Promise<any>`
- Fetches `url` via `fetch(url)`.
- **`.then(res => ...)`**:
  - Treats non-2xx responses (`!res.ok`) as an error by throwing an `Error` whose message includes the status code (e.g. `HTTP ${res.status}`).
  - Resolves with parsed JSON (`res.json()`).
- **`.catch(err => ...)`**:
  - Logs the error via `console.error(...)`.
  - Rethrows `err` so the returned promise rejects downstream.
- **`.finally(() => ...)`**:
  - Calls `console.log(...)` exactly once to signal completion (runs on both success and rejection).
  - Do not call `console.log` anywhere else.
