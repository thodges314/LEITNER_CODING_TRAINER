Implement multi-source and shortest-path Breadth-First Search on 2D grids:

### `orangesRotting(grid: number[][]): number`
- Simulates the rotting of oranges on a grid containing `0` (empty), `1` (fresh), and `2` (rotten).
- In each minute, every fresh orange 4-directionally adjacent to a rotten orange rots.
- Returns the minimum minutes elapsed until no fresh oranges remain.
- Returns `0` if there are initially no fresh oranges; returns `-1` if any fresh orange can never rot.

### `shortestPathBinaryMatrix(grid: number[][]): number`
- Finds the length of the shortest clear path from top-left `(0, 0)` to bottom-right `(n - 1, n - 1)` in an `n x n` binary grid.
- Moves may be made in 8 directions (horizontal, vertical, diagonal) through clear cells (`0`).
- Returns the number of visited cells along the path, or `-1` if blocked or unreachable.

### `updateMatrix(mat: number[][]): number[][]`
- Given an `m x n` binary matrix `mat` of `0`s and `1`s, returns a new matrix where each cell contains the Manhattan distance (4 directions) to the nearest `0`.
