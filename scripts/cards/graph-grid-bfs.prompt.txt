Grids are arrays of rows. Write orangesRotting(grid): cells are 0 empty, 1 fresh, 2 rotten; every minute fresh oranges next to a rotten one (4 directions) rot; return the minutes until none are fresh, 0 if there were none, or -1 if some can never rot (start BFS from all rotten oranges at once). Write shortestPathBinaryMatrix(grid): 0 is open, 1 blocked; moving in 8 directions from the top-left to the bottom-right, return the number of cells on the shortest path or -1 (also -1 if either end is blocked). Write updateMatrix(mat): a 0/1 matrix; return a new matrix where each cell is the distance (4 directions) to the nearest 0.
