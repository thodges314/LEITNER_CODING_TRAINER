Implement a factory function for a React Theme Context:

### createThemeContext(): ThemeContextResult
- Creates an internal React context via `createContext(null)`.
- Returns an object containing `{ ThemeProvider, useTheme }`.

### ThemeProvider({ children, defaultTheme = 'light' }: ThemeProviderProps): JSX.Element:
- Manages theme state (`'light' | 'dark'`) initialized to `defaultTheme` (defaults to `'light'`).
- Provides a context value object: `{ theme, setTheme, toggle }`.
  - `toggle()` flips between `'light'` and `'dark'`.
  - Memoizes callbacks and the context value object where appropriate.

### useTheme(): ThemeContextValue
- Custom hook that consumes the theme context via `useContext`.
- Returns `{ theme, setTheme, toggle }`.
- Throws an `Error` whose message mentions `'ThemeProvider'` when invoked outside of a `<ThemeProvider>`.
