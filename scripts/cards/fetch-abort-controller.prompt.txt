Write an HTTP fetch utility that enforces request timeouts using `AbortController`:

### `fetchWithTimeout(url: string, timeoutMs: number): Promise<any>`
- Creates an `AbortController` and links its signal to `fetch(url, { signal: controller.signal })`.
- Sets a timer via `setTimeout(() => controller.abort(), timeoutMs)`:
  - If the request does not settle within `timeoutMs`, the controller aborts and the returned promise rejects with an `AbortError` (`err.name === 'AbortError'`).
- If the fetch completes successfully before the timeout:
  - Clears the pending timer with `clearTimeout(timer)` so it never fires later.
  - Resolves with the parsed JSON (`await res.json()`).
- On any failure or abort, ensures the timer is cleared before re-throwing or rejecting.
