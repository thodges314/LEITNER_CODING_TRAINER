Write hasCycle(value): true when following object/array properties from value ever reaches an object that is currently being visited (a real cycle: a.self = a, a -> b -> a, an array containing itself). The same object referenced twice from different places (a diamond) is NOT a cycle. Primitives and null have no cycle. Use WeakSets (one for the current path, one for finished objects).

Write countObjects(root): the number of distinct objects and arrays reachable from root, including root itself, counting each only once even with cycles or sharing (0 for primitives and null).
