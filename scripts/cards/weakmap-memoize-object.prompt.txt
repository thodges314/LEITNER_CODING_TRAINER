Write memoizeByObject(fn) returning a function that caches fn's result in a WeakMap keyed by the FIRST argument's identity (the same object returns the cached result without calling fn again, even if the cached result is undefined). If the first argument is not an object or function (primitives, null), do not cache: call fn every time. Also write idOf(obj) returning a stable positive integer id for each object: the same object always gets the same id and each new object gets the next integer (ids increase by 1).
