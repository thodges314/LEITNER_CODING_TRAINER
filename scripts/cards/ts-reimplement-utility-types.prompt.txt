Without using built-in TypeScript utility types, define foundational mapped types:

### `MyPartial<T>`
- Makes every property of `T` optional (`?`).

### `MyReadonly<T>`
- Makes every property of `T` `readonly`.

### `MyPick<T, K extends keyof T>`
- Constructs a type picking only keys `K` from `T`.

### `MyRecord<K extends keyof any, V>`
- Constructs an object type with property keys `K` and values of type `V`.
