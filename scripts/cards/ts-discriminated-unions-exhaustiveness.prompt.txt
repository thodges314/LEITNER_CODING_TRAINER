Define a generic discriminated union and exhaustive state formatter:

### `type AsyncState<T>`
- Discriminated by `status`:
  - `{ status: 'idle' }`
  - `{ status: 'loading' }`
  - `{ status: 'success'; data: T }`
  - `{ status: 'error'; error: Error }`

### `formatState<T>(state: AsyncState<T>): string`
- Uses a `switch` statement that returns:
  - `'Idle'` for `'idle'`
  - `'Loading...'` for `'loading'`
  - `'Loaded: ' + JSON.stringify(state.data)` for `'success'`
  - `'Failed: ' + state.error.message` for `'error'`
- In the `default` branch, assigns `state` to a variable of type `never` (`const _exhaustiveCheck: never = state; throw new Error(...)`), ensuring unhandled statuses fail compilation.
