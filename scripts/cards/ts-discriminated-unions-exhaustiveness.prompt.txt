Define a generic union AsyncState<T> discriminated by `status`: { status: 'idle' }, { status: 'loading' }, { status: 'success'; data: T } and { status: 'error'; error: Error }. Write formatState<T>(state: AsyncState<T>): string using a switch that returns 'Idle', 'Loading...', `Loaded: ${JSON.stringify(data)}` and `Failed: ${error.message}`. In the default branch assign the state to a variable of type never, so adding a new status without handling it is a compile-time error.
