### Countdown(props: CountdownProps): JSX.Element
Build Countdown({ seconds, onDone, tickMs = 1000 }). It renders <span role="timer"> with the remaining seconds and three buttons labelled Start, Pause and Reset. It shows `seconds` and does NOT run until Start is clicked; while running it decrements every tickMs; at 0 it stops and calls onDone exactly once (use the latest onDone). Pause stops the countdown and Start resumes from where it stopped; Reset stops it and restores `seconds`. Start does nothing at 0. Clear the interval on unmount (no onDone after unmounting).
