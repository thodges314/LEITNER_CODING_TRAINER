```ts
interface ToolbarItem {
  id: string;
  label: string;
}
```

### Toolbar({ label, items }: { label: string; items: ToolbarItem[] }): JSX.Element:

Build a toolbar with roving tabindex where `items` is `ToolbarItem[]`.

- **DOM Structure**: Render `<div role="toolbar" aria-label={label} aria-orientation="horizontal">` containing one `<button type="button">` per item displaying its `label`.
- **Roving `tabIndex`**:
  - Only **ONE** button is in the natural `Tab` order at any time: the active button has `tabIndex={0}`; all others have `tabIndex={-1}`.
  - The first button starts active (`tabIndex={0}`).
  - Pressing `Tab` enters the toolbar directly on the active button; the next `Tab` exits the toolbar.
- **Keyboard Navigation**:
  - `ArrowRight` / `ArrowLeft`: Moves focus to the next / previous button and makes it active (wrapping around at boundaries).
  - `Home` / `End`: Jumps focus directly to the first / last button.
  - Call `event.preventDefault()` on handled navigation keys.
- **Activation on Interaction**: Clicking a button, or focusing it through any other means, makes it the active button (`tabIndex={0}`).
