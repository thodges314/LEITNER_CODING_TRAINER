Define recursive template literal string types and a runtime path resolution helper:

### `CamelToKebab<S extends string>`
- Recursively converts a camelCase string literal type to kebab-case (e.g. `'userName'` -> `'user-name'`, `'isReady'` -> `'is-ready'`).

### `Split<S extends string, Delim extends string>`
- Splits string literal `S` by delimiter `Delim` into a tuple of string segments.

### `DeepDotPath<T>`
- Recursively constructs a union of all dot-separated property paths for nested object `T` (e.g. `{ user: { name: string } }` produces `'user' | 'user.name'`).

### `getByPath(obj: any, path: string): any`
- Retrieves the nested value at the dot-separated `path` in `obj`.
- Returns `undefined` if `obj` or `path` is empty or if any intermediate segment is not found.
