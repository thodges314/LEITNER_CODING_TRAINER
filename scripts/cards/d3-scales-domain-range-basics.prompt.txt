## Description

```ts
interface ScaleConfig {
  categories: string[];
  values: number[];
  width: number;
  height: number;
  paddingInner?: number;
  clamp?: boolean;
}

interface PointMapping {
  x: number;
  y: number;
  barWidth: number;
  color: string;
}

interface CoordinateScales {
  xScale: d3.ScaleBand<string>;
  yScale: d3.ScaleLinear<number, number>;
  colorScale: d3.ScaleOrdinal<string, string>;
  mapPoint: (category: string, value: number) => PointMapping | null;
  invertY: (pixelY: number) => number;
}
```

### `createCoordinateScales(config: ScaleConfig): CoordinateScales`

In D3, **Scales** map abstract data domains (`[min, max]` numbers or discrete categories) into visual ranges (pixel positions, dimensions, or color palettes). Because SVG coordinates place `(0, 0)` at the top-left, vertical linear scales use an inverted range `[height, 0]` so that larger values map to smaller Y pixel positions (higher on screen).

Implement `createCoordinateScales` to construct coordinate and color scales from input configuration without touching the DOM.

### Requirements

1. **Discrete Band Scale (`xScale`)**:
   - Construct a `d3.scaleBand()`.
   - Set `.domain(categories)` and `.range([0, width])`.
   - Set `.paddingInner(paddingInner ?? 0.2)`.

2. **Continuous Linear Scale (`yScale`)**:
   - Determine the upper domain bound: `upperBound = (d3.max(values) || 100)`. If `upperBound <= 0`, default to `100`.
   - Set `.domain([0, upperBound])`.
   - Set an inverted range `.range([height, 0])` (so `0` maps to `height` and `upperBound` maps to `0`).
   - Enable clamping: `.clamp(Boolean(clamp))`.

3. **Ordinal Color Scale (`colorScale`)**:
   - Construct a `d3.scaleOrdinal(d3.schemeTableau10)`.
   - Set `.domain(categories)`.

4. **Helper Methods**:
   - `mapPoint(category: string, value: number)`:
     - Look up `x = xScale(category)`. If `x === undefined`, return `null`.
     - Return `{ x, y: yScale(value), barWidth: xScale.bandwidth(), color: colorScale(category) }`.
   - `invertY(pixelY: number)`:
     - Return `yScale.invert(pixelY)`.
