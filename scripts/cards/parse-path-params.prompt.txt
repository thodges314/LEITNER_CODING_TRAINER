Extract named dynamic route parameters from a URL path:

### `parsePath(pattern: string, path: string): Record<string, string> | null`
- Parses dynamic path parameters defined by `:param` segments in `pattern`.
- Example: `parsePath('/users/:id/posts/:postId', '/users/7/posts/42')` returns `{ id: '7', postId: '42' }`.

#### Matching Rules
- Normalizes paths: ignores trailing slashes and discards any query string (`?query`) or hash fragment (`#hash`).
- Compares segment by segment:
  - Dynamic segments (starting with `':'`) extract their corresponding value into the params object.
  - Static segments must match identically.
- Returns `null` if the segment count differs or if any static segment fails to match.
