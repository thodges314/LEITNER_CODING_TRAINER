### Modal(props: ModalProps): JSX.Element | null:
Create `Modal({ isOpen, onClose, children })` rendered with `ReactDOM.createPortal` into `document.body` (renders nothing when closed).

- **Structure**: A backdrop element containing a `role="dialog"` `aria-modal="true"` element wrapping `children`.
- **Dismissal**:
  - Pressing `Escape` calls `onClose`.
  - Clicking the backdrop (but **NOT** the dialog content) calls `onClose`.
- **Focus Management**:
  - Focus moves into the dialog on open and returns to the previously focused element (the trigger) on close.
  - `Tab` / `Shift+Tab` are trapped inside the dialog (wrapping between first and last focusable elements).
- **Body Scroll Lock**:
  - `document.body.style.overflow` is set to `'hidden'` while open and restored when closed.
