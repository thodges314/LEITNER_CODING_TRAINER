Intervals are [start, end] pairs where an interval that ends exactly when another starts does NOT overlap.

Write eraseOverlapIntervals(intervals): the minimum number of intervals to remove so the rest do not overlap (greedy: sort by end, keep the earliest-ending; 0 for []).

Write canAttendMeetings(intervals): true when no two intervals overlap ([] is true). Do not mutate the input.

Write canCompleteCircuit(gas, cost): stations are in a circle, gas[i] is fuel gained at station i and cost[i] the fuel needed to reach the next one; return the index of the station to start at so you can complete the loop (the answer is unique when it exists), or -1.
