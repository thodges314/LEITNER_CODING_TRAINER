Implement a minimal MiddlewarePipeline with use(fn) and handle(req, res). Layers run in order via next(); async handlers are supported. A thrown error or rejected promise skips normal layers and goes to the next error-handling layer (a 4-argument function (err, req, res, next)). An error nobody handles sets res.statusCode = 500. Calling next() more than once from the same layer must be ignored.
