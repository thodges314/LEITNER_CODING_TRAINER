Calculate and compare CSS selector specificity vectors:

### `specificity(selector: string): [ids: number, classes: number, elements: number]`
- Parses a single complex selector string (no top-level commas).
- Returns a 3-tuple `[ids, classes, elements]`:
  - **IDs (`ids`)**: counts `#id` selectors.
  - **Classes (`classes`)**: counts `.class`, `[attribute]` selectors, and `:pseudo-class` selectors.
  - **Elements (`elements`)**: counts type/tag selectors and `::pseudo-element` selectors.
- **Rules & Modifiers**:
  - Combinators (` `, `>`, `+`, `~`) and the universal selector `*` add nothing `[0, 0, 0]`.
  - `:where(X)` adds nothing `[0, 0, 0]`.
  - `:not(X)` adds the specificity of its inner argument `X` (the `:not` pseudo-class itself contributes 0).

### `compareSpecificity(a: string, b: string): 1 | -1 | 0`
- Compares the specificity of two selector strings `a` and `b` by comparing `ids`, then `classes`, then `elements`.
- Returns `1` if selector `a` is more specific than `b`.
- Returns `-1` if selector `b` is more specific than `a`.
- Returns `0` if they have identical specificity.
