Write specificity(selector) for a single complex selector (no commas) returning [ids, classes, elements]: ids count #id; classes count .class, [attribute] and :pseudo-class; elements count type selectors and ::pseudo-elements. The universal selector * and combinators (space > + ~) add nothing; :not(X) adds the specificity of its argument X (not of :not itself); :where(X) adds nothing. Also write compareSpecificity(a, b) taking two selector strings and returning 1 if a is more specific, -1 if b is, and 0 if they tie.
