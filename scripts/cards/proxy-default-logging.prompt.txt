Write withDefaults(target, defaults) returning a Proxy whose get trap returns target[key] when the key exists in target (use `key in target`), otherwise defaults[key] (undefined if neither has it). Write countAccesses(target) returning { proxy, counts }: proxy forwards reads to target (use Reflect.get) and records in the plain object counts how many times each STRING key was read (counts.a is 2 after two reads of proxy.a; symbol keys are not counted).
