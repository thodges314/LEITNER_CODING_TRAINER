Write negativeIndex(arr) returning a Proxy around the array so that negative indices count from the end: p[-1] is the last element, p[-2] the one before. Reads beyond the start (p[-n] with n > length) give undefined. Assigning p[-1] = x overwrites the last element; assigning with a negative index beyond the start throws a RangeError whose message contains 'out of range'. Everything else (non-negative indices, length, push, map, Array.isArray) must keep working. Negative indices arrive in the traps as STRING keys like '-1'.
