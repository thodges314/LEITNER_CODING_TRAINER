Implement class MyPromise(executor) without using the native Promise for its own state. Requirements: it settles once (extra resolve/reject calls are ignored); an executor that throws rejects it; then(onFulfilled, onRejected) returns a NEW MyPromise and its callbacks always run asynchronously (as microtasks), even if already settled; a handler's return value resolves the derived promise, a returned promise/thenable is adopted, and a throw rejects it; a missing handler passes the value/reason through; resolving a promise with itself rejects with a TypeError. Also implement catch(onRejected), finally(fn) (runs on both outcomes and passes the original result/reason through) and static resolve(value) / reject(reason).
