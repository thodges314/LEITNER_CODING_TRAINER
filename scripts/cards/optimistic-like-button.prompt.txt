Build LikeButton({ initialLiked = false, initialCount = 0, onToggle }) where onToggle(nextLiked) returns a Promise. Render <button aria-pressed={liked}>{liked ? 'Unlike' : 'Like'} ({count})</button>. Clicking updates the UI IMMEDIATELY (flip liked, count +1 or -1) and calls onToggle(nextLiked). If the promise rejects, roll back to the previous liked/count and show <p role="alert">Could not update</p>; the alert disappears on the next click. While a request is pending, further clicks are ignored.
