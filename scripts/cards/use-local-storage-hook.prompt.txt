Write useLocalStorage(key, initialValue) returning [value, setValue]. It reads and JSON-parses the stored value on first render (falling back to initialValue when nothing is stored or the stored text is corrupt), setValue accepts a value or an updater function (even when called twice in one batch) and writes JSON to localStorage, a 'storage' event for the same key (another tab) updates the value (a removal restores initialValue; other keys are ignored), and changing `key` reads the new key.
