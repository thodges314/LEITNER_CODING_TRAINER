Write async text copying utility with HTML5 Clipboard API and DOM textarea fallback:

### `copyToClipboard(text: string, env?: { navigator?: any; document?: any }): Promise<boolean>`

`env` holds the browser objects to use (`{ navigator, document }`) so they can be replaced in tests: use the browser global only when that key is missing from `env`, and treat an explicit `null` or `undefined` value as "not available".

1. **Async Clipboard API**: If `env.navigator.clipboard.writeText` exists, `await` it and resolve `true`. If it is missing or its promise rejects, fall back.
2. **Fallback**: Create a `<textarea>` with `document.createElement`, set its `value` to the text, mark it `readonly`, and move it off screen (`style.position = 'fixed'`, `style.left = '-9999px'`). Append it to `document.body`, call `select()` on it, then run `document.execCommand('copy')` and resolve with its boolean result.
3. **Cleanup**: Always remove the `<textarea>` from `document.body` afterwards, even when `execCommand` throws (a throw resolves `false`). If there is no document, resolve `false`.
