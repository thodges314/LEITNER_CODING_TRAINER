Build Pagination({ page, totalPages, onPageChange, siblings = 1 }) as a controlled component. Render <nav aria-label="Pagination"> with <button>Previous</button>, a <ul> of <li> items and <button>Next</button>. The list always shows page 1, the last page and the pages within `siblings` of the current page; between two shown pages: if exactly ONE page is missing show that page, if more are missing show an <li><span>…</span></li> (not clickable). Each page is <li><button>N</button></li>; the current page's button has aria-current="page". Clicking a page calls onPageChange(n); Previous/Next call it with page-1 / page+1 and are disabled on the first/last page.
