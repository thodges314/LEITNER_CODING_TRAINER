Build an accessible pagination bar as a controlled component:

### Pagination({ page, totalPages, onPageChange, siblings = 1 }: { page: number; totalPages: number; onPageChange: (page: number) => void; siblings?: number }): JSX.Element:
- **DOM Structure**: Render `<nav aria-label="Pagination">` containing `<button>Previous</button>`, a `<ul>` of `<li>` items, and `<button>Next</button>`.
- **Page Display Rules**:
  - The list always shows page `1`, the last page (`totalPages`), and the pages within `siblings` distance of the current `page`.
  - Between shown pages: if exactly **ONE** page is missing, render that page number; if more than one page is missing, render an `<li><span>…</span></li>` ellipsis (not clickable).
- **Page Buttons & ARIA**:
  - Each page item is `<li><button>N</button></li>`.
  - The current page's button has `aria-current="page"`.
- **Navigation Actions**:
  - Clicking a page button calls `onPageChange(n)`.
  - `Previous` and `Next` buttons call `onPageChange(page - 1)` / `onPageChange(page + 1)`.
  - `Previous` is disabled on the first page; `Next` is disabled on the last page.
