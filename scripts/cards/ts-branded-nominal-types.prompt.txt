Define a generic nominal branding type and brand constructor functions to prevent accidental assignment between identical underlying primitives:

### `Brand<K, T>`
- Intersects type `K` with `{ readonly __brand: T }`.

### Branded Types
- `type UserId = Brand<string, 'UserId'>`
- `type OrderId = Brand<string, 'OrderId'>`
- `type PositiveNumber = Brand<number, 'PositiveNumber'>`

### `toUserId(id: string): UserId`
- Casts a string to `UserId`.

### `toOrderId(id: string): OrderId`
- Casts a string to `OrderId`.

### `toPositiveNumber(n: number): PositiveNumber`
- If `n <= 0`, throws an `Error('Number must be positive')`.
- Otherwise, returns `n` cast to `PositiveNumber`.
