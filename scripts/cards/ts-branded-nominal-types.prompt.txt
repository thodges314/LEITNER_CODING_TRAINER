Define a generic Brand helper and nominal ID types:
- type Brand<K, T>: intersects primitive K with { readonly __brand: T } so identical primitives with different brands cannot be assigned to each other.
- type UserId = Brand<string, 'UserId'>
- type OrderId = Brand<string, 'OrderId'>
- type PositiveNumber = Brand<number, 'PositiveNumber'>
- function toUserId(id: string): UserId: casts a string to UserId.
- function toOrderId(id: string): OrderId: casts a string to OrderId.
- function toPositiveNumber(n: number): PositiveNumber: throws an Error('Number must be positive') if n <= 0, otherwise returns n as PositiveNumber.
