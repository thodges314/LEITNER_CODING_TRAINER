Write lazyLoadImages(root, IO = the global IntersectionObserver) that lazy-loads images. Find every `img[data-src]` inside root and observe each one with a new IO(callback, { rootMargin: '200px' }). When the callback receives an entry with isIntersecting true, copy the image's data-src into its src, remove the data-src attribute, and unobserve that image (entries that are not intersecting do nothing, and an image that was already loaded must not be loaded again if a stray entry arrives). Return a function that stops everything by calling observer.disconnect(). If IO is not available (null or undefined, e.g. an old browser), load every image immediately and return a function that does nothing.
