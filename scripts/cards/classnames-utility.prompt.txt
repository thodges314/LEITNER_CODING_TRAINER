Implement a conditional CSS class name joining utility (similar to `clsx` or `classnames`):

### `classNames(...args)`
- Joins valid class name tokens with a single space `' '` in the order received.
- **Strings and Numbers**:
  - Non-empty strings and numbers are converted to strings and included.
  - Falsy values (`''`, `0`, `null`, `undefined`, `false`) are omitted.
- **Arrays**:
  - Flattened recursively; each nested element is evaluated using the same rules.
- **Objects**:
  - For each key in the object, includes the key name if its associated value is truthy.
- Calling `classNames()` with no arguments returns an empty string `''`.
