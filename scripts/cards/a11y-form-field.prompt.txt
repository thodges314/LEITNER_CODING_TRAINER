Build two small accessible components. ToggleButton({ pressed, onPressedChange, children }) renders <button type="button" aria-pressed={pressed}> and calls onPressedChange(!pressed) when clicked. FormField({ label, hint, error, children }) renders a <label htmlFor> with the label text, then calls children(props) — a render function — where props = { id, 'aria-describedby', 'aria-invalid' }, then the optional hint <p id> and error <p id role="alert">. Generate ids with useId; 'aria-describedby' lists the ids of the hint and/or error that are present (space-separated) and is undefined when neither exists; 'aria-invalid' is true only when there is an error (otherwise undefined).
