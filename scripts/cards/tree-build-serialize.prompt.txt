Tree nodes are { val, left, right } (null for a missing child). Write buildTree(preorder, inorder): rebuild the tree from its preorder and inorder arrays (all values distinct; [] gives null) in O(n) using a value-to-index map. Write serialize(root): any string encoding of the tree (it must handle null, negative and multi-digit values), and deserialize(str): the exact inverse, so deserialize(serialize(t)) rebuilds a tree structurally equal to t and deserialize(serialize(null)) is null.
