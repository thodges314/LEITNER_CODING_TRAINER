Implement tree reconstruction and serialization algorithms on nodes shaped `{ val, left, right }`:

### `buildTree(preorder: number[], inorder: number[]): TreeNode<number> | null`
- Reconstructs a binary tree from its `preorder` and `inorder` traversal arrays (where all node values are distinct).
- Operates in O(n) time complexity using a value-to-index map for `inorder` lookups.
- Returns `null` if the arrays are empty (`[]`).

### `serialize(root: TreeNode<number> | null): string`
- Encodes a binary tree into a single string representation.
- Must reliably encode `null` children, negative values, and multi-digit integers.

### `deserialize(str: string): TreeNode<number> | null`
- Reconstructs the exact binary tree from the serialized string `str`.
- Guaranteed inverse: `deserialize(serialize(t))` produces a tree structurally equal to `t`, and `deserialize(serialize(null))` returns `null`.
