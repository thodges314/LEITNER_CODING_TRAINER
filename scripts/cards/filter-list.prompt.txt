### FilterList(props: FilterListProps): JSX.Element:
Build a filterable list component for an array of strings:

- **Search Input**:
  - Controlled `<input aria-label="Filter" value={query} onChange={...} />`.
- **Filtering Logic**:
  - Case-insensitive substring match on the trimmed search query (`query.trim().toLowerCase()`).
  - An empty or whitespace-only query displays all `items`.
  - Derive the filtered list directly during render without storing duplicate lists in state.
- **Render Output**:
  - `<ul>` rendering one `<li>` per matching item.
  - `<p role="status">` announcing results:
    - `'5 results'` (plural for counts $\ne$ 1).
    - `'1 result'` (singular).
    - `'No matches'` (when 0 items match).
