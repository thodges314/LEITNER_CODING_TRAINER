Write parseQuery(query) and stringifyQuery(params). parseQuery accepts a string with or without a leading '?', splits on & and =, decodes percent-escapes and '+' as a space, treats a key without '=' as '' and repeated keys as an array of values (in order); '' parses to {}. stringifyQuery takes a flat object and returns key=value pairs joined by '&' in key order, percent-encoding keys and values with encodeURIComponent, emitting one pair per array item and skipping undefined and null values.
