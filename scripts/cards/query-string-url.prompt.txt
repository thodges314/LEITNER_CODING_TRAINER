Implement URL query string serialization and deserialization helpers:

### `parseQuery(query: string): Record<string, string | string[]>`
- Parses a query string (with or without a leading `'?'`) into an object:
  - Splits pairs on `'&'` and key/value on `'='`.
  - Decodes percent-encoded characters and converts `'+'` into a space `' '`.
  - Keys without an `'='` delimiter map to an empty string `''`.
  - Repeated keys are collected into an array of string values in order of appearance.
  - An empty string `''` parses to `{}`.

### `stringifyQuery(params: Record<string, unknown>): string`
- Converts an object of parameters into a serialized query string:
  - Generates `'key=value'` pairs joined by `'&'`.
  - Encodes both keys and values using `encodeURIComponent()`.
  - If a value is an array, emits one `'key=value'` pair per element.
  - Skips properties whose values are `undefined` or `null`.
