React 19 can read a promise during render with the use() API. Build UserBadge({ userPromise }), where userPromise resolves to { name, role }.

UserBadge renders a <Suspense fallback={<p>Loading…</p>}> (the text is exactly "Loading…") around a child component that calls use(userPromise) and renders <p>{name} ({role})</p>, for example "Ada (admin)".

The parent creates the promise and keeps it the same across re-renders, so never create a promise inside the component. Do not catch errors: when the promise rejects, the error must reach the nearest error boundary. `use` and `Suspense` are available as plain names.
