Implement an undo/redo history manager:

### `createHistory(initial)`
- Tracks `past` entries, the current `present` value (starts as `initial`), and `future` entries.
- Returns an object providing the following methods:

#### Inspection Methods
- **`getPresent()`**: Returns the current present value.
- **`canUndo()`**: Returns `true` if there are entries in the past history to undo, `false` otherwise.
- **`canRedo()`**: Returns `true` if there are undone entries in the future history to redo, `false` otherwise.

#### Mutation Methods
- **`push(value)`**:
  - If `Object.is(value, present)`, does nothing and returns `present` without creating a history entry.
  - Otherwise, pushes `present` onto the `past` stack, sets `present = value`, and clears all `future` history.
  - Returns `present`.
- **`undo()`**:
  - If `canUndo()`, moves `present` onto `future` and pops the previous state from `past` to become `present`.
  - Does nothing if there is nothing to undo.
  - Returns `present`.
- **`redo()`**:
  - If `canRedo()`, moves `present` onto `past` and pops the next state from `future` to become `present`.
  - Does nothing if there is nothing to redo.
  - Returns `present`.
