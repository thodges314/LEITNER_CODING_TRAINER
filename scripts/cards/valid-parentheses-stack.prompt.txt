Implement bracket validation using a stack:

### `isValidParentheses(s)`
- Determines whether a string consisting of `(`, `)`, `{`, `}`, `[`, and `]` has valid bracket nesting.
- **Rules**:
  - Open brackets must be closed by the matching bracket type (`()` `{}` `[]`).
  - Open brackets must close in the correct order (properly nested, not interleaved).
  - Returns `false` for unclosed openers or a closing bracket without an opener.
  - An empty string `''` is valid (`true`).
