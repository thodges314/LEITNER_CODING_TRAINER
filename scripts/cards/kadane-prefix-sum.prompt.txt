Implement array subarray and product problems in $O(n)$ time:

### `maxSubarray(nums: number[]): number`
Finds the largest possible sum of any non-empty contiguous subarray.
- **Examples**:
  - `maxSubarray([-2, 1, -3, 4, -1, 2, 1, -5, 4])` $\to$ `6` (subarray `[4, -1, 2, 1]`).
  - `maxSubarray([5, 4, -1, 7, 8])` $\to$ `23` (the entire array).
  - `maxSubarray([-3, -1, -2])` $\to$ `-1` (all-negative array returns the largest single element) and `maxSubarray([])` $\to$ `0`.

### `productExceptSelf(nums: number[]): number[]`
Returns an array `output` where `output[i]` is the product of every element in `nums` **except** `nums[i]`, **without** using the division operator `/`:

$$\text{output}[i] = \prod_{j \neq i} x_j$$

- **Examples**:
  - `productExceptSelf([1, 2, 3, 4])` $\to$ `[24, 12, 8, 6]`.
  - `productExceptSelf([-1, 1, 0, -3, 3])` $\to$ `[0, 0, 9, 0, 0]` (one zero makes every other position `0`, while the zero's position gets the product of the rest).
  - `productExceptSelf([0, 0, 2])` $\to$ `[0, 0, 0]` (two or more zeros make every position `0`).

### `subarraySum(nums: number[], k: number): number`
Counts how many contiguous subarrays have elements summing to `k`.
- **Examples**:
  - `subarraySum([1, 1, 1], 2)` $\to$ `2` (`[1, 1]` at indices `0..1` and `1..2`).
  - `subarraySum([1, 2, 3], 3)` $\to$ `2` (`[1, 2]` and `[3]`).
  - `subarraySum([1, -1, 0], 0)` $\to$ `3` (`[1, -1]`, `[0]`, and `[1, -1, 0]`).
