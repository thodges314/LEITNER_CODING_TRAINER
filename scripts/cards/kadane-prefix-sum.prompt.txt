Implement array prefix sum, product, and dynamic programming algorithms in $O(n)$ time:

$$\text{cur}_i = \max(x_i,\; \text{cur}_{i-1} + x_i), \qquad \text{output}[i] = \left(\prod_{j < i} x_j\right) \left(\prod_{j > i} x_j\right)$$

### `maxSubarray(nums: number[]): number`
Finds the largest possible sum of any non-empty contiguous subarray using **Kadane's algorithm**.
- At each element `x`, either extend the previous subarray (`cur + x`) or start fresh at `x`, tracking the global maximum.
- **Example**: `maxSubarray([-2, 1, -3, 4, -1, 2, 1, -5, 4])` returns `6` (subarray `[4, -1, 2, 1]`).
- **Edge Cases**: Correctly handles all-negative arrays (e.g. `[-3, -1, -2]` $\to$ `-1`), and returns `0` if `nums` is empty.

### `productExceptSelf(nums: number[]): number[]`
Returns an array `output` where `output[i]` is the product of every element in `nums` **except** `nums[i]`, **without** using division `/`.
- Use two passes: first accumulate the left-prefix product into `output[i]`, then sweep right-to-left multiplying by a running suffix product.
- **Example**: `productExceptSelf([1, 2, 3, 4])` returns `[24, 12, 8, 6]`.

### `subarraySum(nums: number[], k: number): number`
Counts how many contiguous subarrays sum to `k`.
- Track running prefix sum `sum` and store how many times each prefix sum has occurred in a `Map` (seeded with `{ 0: 1 }`). Whenever `sum - k` has appeared `c` times before, there are `c` valid subarrays ending at the current index ($P[r] - P[l] = k$).
- **Example**: `subarraySum([1, 1, 1], 2)` returns `2` (`[1, 1]` at indices `0..1` and `1..2`).
