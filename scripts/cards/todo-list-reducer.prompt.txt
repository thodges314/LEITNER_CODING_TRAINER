Implement immutable state logic and selectors for a todo list:

### todoReducer(state: TodoState, action: TodoAction): TodoState
- State shape: `{ todos: [{ id, text, done }], filter: 'all' | 'active' | 'done' }`.
- Never mutates state directly.
- Handles action types:
  - `'ADD'`: adds `{ id: action.id, text: action.text, done: false }` to `todos`.
  - `'TOGGLE'`: inverts the `done` boolean on the todo matching `action.id`.
  - `'EDIT'`: updates `text` of the todo matching `action.id` to `action.text`.
  - `'DELETE'`: removes the todo with `id === action.id`.
  - `'SET_FILTER'`: updates `filter` to `action.filter`.
  - Default: returns the exact same `state` reference for unknown action types.

### selectVisibleTodos(state: TodoState): Todo[]
- Computes visible todos based on `state.filter`:
  - `'active'`: returns todos where `!t.done`.
  - `'done'`: returns todos where `t.done`.
  - `'all'` (or default): returns all `state.todos`.

### selectCounts(state: TodoState): TodoCounts
- Computes summary counts across `state.todos`:
- Returns `{ total, active, done }`.
