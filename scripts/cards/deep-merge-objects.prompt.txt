Implement recursive object merging with prototype pollution defenses:

### `deepMerge(target, ...sources)`
- Recursively merges all `sources` into `target` (or a fresh target object) without mutating any source.
- **Value Semantics**:
  - Plain objects are merged recursively by key.
  - Arrays, non-plain objects, and primitive values in later sources replace earlier values completely.
  - `undefined` values in a source do not overwrite existing values.
- **Security & Safety**:
  - Protects against prototype pollution by ignoring keys `__proto__`, `constructor`, and `prototype`.
- Returns the merged object.
