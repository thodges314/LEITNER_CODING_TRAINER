Write deepMerge(target, ...sources) that returns a NEW object combining target and then each source from left to right (later sources win). Plain objects are merged recursively; every other value replaces the previous one: primitives, null, arrays (replaced as a whole, never concatenated or merged by index), and non-plain objects such as Date or class instances (kept by reference). A source value of undefined is ignored (it does not erase an existing value), while null does replace. A target or source that is null or undefined is skipped. Nothing is mutated, and the result never shares a plain object or array with an input (copy them, including plain objects inside arrays). Never copy the keys '__proto__', 'constructor' or 'prototype' (prototype pollution): Object.prototype must stay untouched even for input such as JSON.parse('{"__proto__": {"polluted": true}}').
