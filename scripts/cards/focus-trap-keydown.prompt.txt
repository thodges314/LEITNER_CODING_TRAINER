Write `createFocusTrap(getFocusable, doc)` returning a keydown handler `handleKeydown(event)` that traps `Tab` focus within a dialog:

- **Context**:
  - `getFocusable()`: Returns an array of currently focusable elements in DOM tab order. Call it dynamically on each `keydown` as dialog contents can change.
  - `doc.activeElement`: The element that currently holds focus.
- **Key Handling**:
  - Only the `Tab` key is intercepted; all other keys are ignored.
  - If `getFocusable()` returns an empty list, call `event.preventDefault()` and do nothing else.
- **Forward `Tab` (without `Shift`)**:
  - If focus is on the last focusable element, or outside the dialog elements: call `event.preventDefault()` and move focus to the first element.
  - Otherwise, do nothing (allow normal browser tab movement).
- **Reverse `Tab` (`Shift + Tab`)**:
  - If focus is on the first focusable element, or outside the dialog elements: call `event.preventDefault()` and move focus to the last element.
  - Otherwise, do nothing (allow normal browser tab movement).
