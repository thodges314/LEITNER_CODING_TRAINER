Write createFocusTrap(getFocusable, doc) that keeps Tab inside a dialog, and returns a keydown handler handleKeydown(event). getFocusable() returns the array of focusable elements currently inside the dialog, in tab order (call it on every keydown, because the dialog's content can change); doc.activeElement is the element that has focus now. Only the Tab key is handled; every other key is ignored. With an empty list, call event.preventDefault() and do nothing else. On Tab (no Shift): if focus is on the last element, or is not one of the dialog's elements, call event.preventDefault() and focus the first element. On Shift+Tab: if focus is on the first element, or is not one of the dialog's elements, call event.preventDefault() and focus the last element. In every other case do nothing, so the browser moves focus normally.
