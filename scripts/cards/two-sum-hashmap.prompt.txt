Write twoSum(nums, target) returning the indices [i, j] (with i < j) of two different elements whose values add up to target, in O(n) time with a single pass using a hash map. Duplicate values are fine when they sit at different indices (twoSum([3, 3], 6) -> [0, 1]); the same element cannot be used twice (twoSum([5], 10) -> []); if no pair exists, return []. Assume at most one valid answer.
