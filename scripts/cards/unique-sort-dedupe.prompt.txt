Implement record deduplication and multi-key stable sorting:

### `dedupeAndSort<T extends { id: string | number }>(records: T[], sortBy: string | string[] = 'id'): T[]`
- **Deduplication**:
  - Deduplicates records by `id`. When duplicate IDs occur, the latest record in `records` wins.
- **Sorting**:
  - Sorts records by one property key or an array of keys (`sortBy`).
  - Earlier keys take priority over later keys when comparing elements.
  - Sorting is stable: elements with equal keys maintain their relative order.
- **Comparator Handling**:
  - Handles strings (lexicographical comparison via `localeCompare`) and numbers.
  - `null` and `undefined` values sort last.
- Returns a new array without mutating the input `records`.
