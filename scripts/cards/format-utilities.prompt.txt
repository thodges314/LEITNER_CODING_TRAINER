Implement common formatting utility functions without relying on the `Intl` API:

### `formatNumber(n: number, decimals: number = 0): string`
- Formats number `n` with thousands separators (`','`) and fixed `decimals` places (e.g., `'1,234,567.89'`).
- Negative numbers preserve their leading minus sign.
- Helpful thousands separator regex: `/\B(?=(\d{3})+(?!\d))/g` (e.g. `integerPart.replace(/\B(?=(\d{3})+(?!\d))/g, ',')`).


### `formatBytes(bytes: number, decimals: number = 1): string`
- Formats byte count using 1024-based units (`'B'`, `'KB'`, `'MB'`, `'GB'`, `'TB'`).
- Strips redundant trailing decimal zeros (e.g., `1024` -> `'1 KB'`, `1536` -> `'1.5 KB'`, `0` -> `'0 B'`).

### `timeAgo(timestampMs: number, nowMs: number = Date.now()): string`
- Calculates relative time difference between `timestampMs` and `nowMs`:
  - Returns `'just now'` for differences under 60 seconds.
  - Otherwise expresses time using the largest unit rounded to a whole number: `minute` (60s), `hour` (3600s), `day` (86400s), `month` (30 days), `year` (365 days).
  - Handles singular and plural units (`'1 hour ago'`, `'5 minutes ago'`, `'in 3 hours'`).

### `truncate(str: string, max: number): string`
- Shortens `str` to at most `max` characters including a trailing ellipsis character `'…'`.
- If `str.length <= max`, returns `str` unchanged.
