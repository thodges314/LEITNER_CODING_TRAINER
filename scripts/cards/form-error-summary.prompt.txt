```ts
interface SignupFormValues {
  name: string;
  email: string;
}

interface SignupFormProps {
  onSubmit: (values: SignupFormValues) => void;
}
```

### SignupForm({ onSubmit }: SignupFormProps): JSX.Element

Build a signup form with two labelled text inputs: Name (`id="name"`) and Email (`id="email"`), and a submit button inside `<form noValidate>` (validating only on submit).

- **Validation Rules**:
  - **Name**: Must not be blank after trimming (error message: `'Enter your name'`).
  - **Email**: Must match `/^\S+@\S+\.\S+$/` after trimming (error message: `'Enter a valid email address'`).
  - **Valid Submission**: When all fields are valid, call `onSubmit({ name, email })` with trimmed values and clear any existing error summary.
- **Error Summary (on invalid submit)**:
  - Rendered above form fields: `<div role="alert">` containing `<h2 tabIndex={-1}>There is a problem</h2>`.
  - An unordered list with one link per error in field order: `<a href="#name">` and/or `<a href="#email">`, displaying the error message.
  - Automatically moves focus to `<h2>` on every invalid submit.
  - Clicking a summary link prevents default browser hash jump and programmatically focuses the matching `<input>`.
- **Field-Level Accessibility**:
  - Mark each invalid input with `aria-invalid="true"` and `aria-describedby="<id>-error"`.
  - Render the error message in `<p id="<id>-error">` directly below the input.
  - Valid inputs receive neither attribute.
