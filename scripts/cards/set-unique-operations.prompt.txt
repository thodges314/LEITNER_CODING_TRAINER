Write three functions using a Set, each in O(n + m): arrayIntersection(a, b) (unique elements present in both, in order of first appearance in b), arrayUnion(a, b) (unique elements of either, a's elements first) and arrayDifference(a, b) (unique elements of a that are not in b, in a's order). (Note: ensure arrayIntersection strictly maintains b's appearance order regardless of input lengths; native Set.prototype.intersection reverses iteration order when b has more elements than a).
