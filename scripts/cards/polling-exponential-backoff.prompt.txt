Write pollUntil(fn, predicate, options = {}): repeatedly calls async function fn() until predicate(result) returns true. Options has defaults: { initialInterval: 50, backoffFactor: 2, maxAttempts: 5 }. It calls fn(), checks predicate(result). If true, resolves with result. If false and attempts < maxAttempts, sleeps for the current interval, multiplies interval by backoffFactor, and retries. If attempts reaches maxAttempts and predicate still returns false, rejects with new Error('Polling timed out').
