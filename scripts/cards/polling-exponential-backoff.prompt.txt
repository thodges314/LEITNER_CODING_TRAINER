Write `pollUntil(fn, predicate, options = {})`:

- Repeatedly calls `async` function `fn()` until `predicate(result)` returns `true`.
- **Options & Defaults**: `{ initialInterval = 50, backoffFactor = 2, maxAttempts = 5 }`.
- **Polling Loop**:
  - Calls `fn()` and passes the result to `predicate(result)`.
  - If `predicate(result)` is `true`, resolves immediately with `result`.
  - If `false` and `attempts < maxAttempts`, sleeps for the current interval, multiplies interval by `backoffFactor`, and retries.
- **Timeout**: If `attempts` reaches `maxAttempts` and `predicate` continues returning `false`, rejects with `new Error('Polling timed out')`.
