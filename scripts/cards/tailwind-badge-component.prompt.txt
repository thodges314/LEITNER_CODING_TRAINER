### `Badge({ variant = 'neutral', size = 'md', dot = false, children, ...props }: BadgeProps): JSX.Element`

## Description

```ts
type BadgeVariant = 'success' | 'warning' | 'danger' | 'info' | 'neutral';
type BadgeSize = 'sm' | 'md';

interface BadgeProps {
  variant?: BadgeVariant;
  size?: BadgeSize;
  dot?: boolean;
  children?: any;
  [key: string]: any;
}
```

Status badges communicate system telemetry, deployment stages, and data health using semantic color tokens with high contrast and translucent fills.

Build an accessible, responsive status badge React component styled with Tailwind CSS utility classes:

### Requirements

- **Badge Container (`<span>`)**:
  - Uses inline-flex centered layout, medium font weight, pill rounding (`rounded-full`), a border, and color transitions.
  - Forwards extra props (such as `data-testid` or `aria-label`) to the outer `<span>`.

- **Variant Styling & Translucent Tokens**:
  - Apply subtle translucent background fills, readable text, and matching translucent borders for each semantic variant:
    - `'success'`: emerald/green tones
    - `'warning'`: amber/yellow tones
    - `'danger'`: rose/red tones
    - `'info'`: sky/blue tones
    - `'neutral'` (default): midtone slate/gray tones

- **Sizes & Spacing**:
  - `'sm'`: extra-small text, compact padding, and tight flex gap.
  - `'md'` (default): small text, slightly wider padding, and standard flex gap.

- **Dot Indicator (`dot: true`)**:
  - When `dot` is `true`, renders a decorative `<span aria-hidden="true"></span>` before `children`.
  - Styled as a non-shrinking circle (`rounded-full shrink-0`) that scales down for `'sm'` vs `'md'` and uses a background color matching the active variant.
