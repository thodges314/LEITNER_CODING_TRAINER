These are the rules behind a tag (chip) input. None of the functions changes the array it is given; each returns a new array.

addTag(tags, input, { max = Infinity } = {}): trim the input. Add it at the end only when it is not empty, is not already in the list (compare ignoring upper/lower case; the first spelling stays), and the list does not already hold max tags. Otherwise return a copy of the list unchanged.

removeTag(tags, index): the list without the tag at index (an index that does not exist changes nothing).

parseTags(text): for pasted text, split on commas and line breaks, then apply the same rules as addTag to every part (so blanks and repeats are dropped): parseTags('a, b,\n A ,,C') is ['a', 'b', 'C'].
