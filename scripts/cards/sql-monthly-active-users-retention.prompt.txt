Write a PostgreSQL query to calculate the number of retained active users for each calendar month.

A user is considered "retained" in month $M$ if they performed at least one action in both month $M-1$ and month $M$.

### Schema: `user_actions`
- `user_id` (INT): Unique user identifier.
- `action_date` (DATE): Date of the user action.
- `action_type` (VARCHAR): Action name (e.g. `'login'`, `'purchase'`, `'view'`).

### Query Contract
- Output columns: `month` (formatted as `'YYYY-MM'`), `retained_users` (integer count of distinct users who were active in both that month and the immediately preceding month).
- Only include months that have at least one retained user (`retained_users > 0`).
- Cast count to integer (or `COUNT(DISTINCT ...) :: INT`).
- Sort results by `month` ascending (`ORDER BY month ASC`).
- If no users are retained or if `user_actions` is empty, return an empty result set (0 rows).

### Example
Given `user_actions` records:
- `{ user_id: 1, action_date: "2024-01-15", action_type: "login" }`
- `{ user_id: 2, action_date: "2024-01-20", action_type: "login" }`
- `{ user_id: 1, action_date: "2024-02-05", action_type: "purchase" }`
- `{ user_id: 3, action_date: "2024-02-18", action_type: "login" }`
- `{ user_id: 1, action_date: "2024-03-12", action_type: "login" }`
- `{ user_id: 3, action_date: "2024-03-25", action_type: "login" }`

The query returns:
- `[{ "month": "2024-02", "retained_users": 1 }, { "month": "2024-03", "retained_users": 2 }]`

Explanation:
- In `2024-02`, only user 1 was active in both January and February (count: 1).
- In `2024-03`, users 1 and 3 were active in both February and March (count: 2).
