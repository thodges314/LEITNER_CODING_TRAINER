```ts
interface BreadcrumbsProps {
  pathname: string;
  labels?: Record<string, string>;
}
```

Implement an accessible React breadcrumb navigation component:

### Breadcrumbs({ pathname, labels = {} }: BreadcrumbsProps): JSX.Element
- Normalizes consecutive or trailing slashes in `pathname` (e.g. `'/products/123/'` -> segments `['products', '123']`).
- Always includes a root crumb `{ path: '/', label: labels['/'] || 'Home' }`.
- For each subpath segment, constructs the cumulative route path (e.g. `'/products'`, `'/products/123'`).
- Resolves each crumb label from `labels[path]` if specified; otherwise defaults to capitalizing the path segment (e.g. `'products'` -> `'Products'`).
- Renders an accessible `<nav aria-label="Breadcrumb">` wrapping an ordered list `<ol className="breadcrumbs">`.
- For each crumb, renders an `<li className="breadcrumb-item">`:
  - Preceding crumbs render an anchor link `<a href={crumb.path}>{crumb.label}</a>`.
  - The current/active page crumb (the final segment, or `'/'` if at root) renders `<span aria-current="page">{crumb.label}</span>` instead of a link.
