### `runHeadlessForceSimulation(nodes: ForceSimNode[], links?: ForceSimLink[], options?: ForceSimOptions): ForceSimReport`

## Description

```ts
interface ForceSimNode {
  id: string;
  x?: number;
  y?: number;
  vx?: number;
  vy?: number;
  radius?: number;
}

interface ForceSimLink {
  source: string | ForceSimNode;
  target: string | ForceSimNode;
  distance?: number;
}

interface ForceSimOptions {
  width?: number;
  height?: number;
  chargeStrength?: number;
  linkDistance?: number;
  collisionRadius?: number;
  alphaMin?: number;
  maxTicks?: number;
}

interface ForceSimReport {
  nodes: ForceSimNode[];
  links: ForceSimLink[];
  ticks: number;
  finalAlpha: number;
  converged: boolean;
}
```

In server-side graph rendering, static layout pre-computation, and large-scale network visualization, running an asynchronous animation loop on the browser main thread is unnecessary or too slow. Instead, `d3.forceSimulation` can be executed **headlessly** by stopping its internal timer (`sim.stop()`) and stepping through discrete numerical integration ticks (`sim.tick()`) synchronously until `alpha` decays below `alphaMin` or a maximum tick budget is reached.

Implement `runHeadlessForceSimulation(nodes, links, options)` to configure a multi-body physics simulation, step it synchronously to convergence, and return the settled layout.

### Requirements

- **Immutability & Defaults**:
  - Do not mutate the caller's input `nodes` or `links` arrays; clone each node (`{ ...n, radius: typeof n.radius === 'number' ? n.radius : collisionRadius }`) and link (`{ ...l }`).
  - Option defaults:
    - `width = 400`, `height = 300`
    - `chargeStrength = -120`
    - `linkDistance = 60`
    - `collisionRadius = 8`
    - `alphaMin = 0.01`
    - `maxTicks = 300`
  - If `nodes` is empty (`[]`) or non-array, return `{ nodes: [], links: [], ticks: 0, finalAlpha: 1, converged: true }`.

- **Force Configuration & Headless Stepping**:
  - Initialize `sim = d3.forceSimulation(nodesCopy)` and immediately call `sim.stop()` to halt background timers.
  - Set `sim.alphaMin(alphaMin)`.
  - Register four forces:
    - `'charge'`: `d3.forceManyBody().strength(chargeStrength)`
    - `'center'`: `d3.forceCenter(width / 2, height / 2)`
    - `'collide'`: `d3.forceCollide((d) => typeof d.radius === 'number' ? d.radius : collisionRadius)`
    - `'link'`: `d3.forceLink(linksCopy).id((d) => d.id).distance((l) => typeof l.distance === 'number' ? l.distance : linkDistance)`
  - Step synchronously while `sim.alpha() >= alphaMin && ticks < maxTicks`:
    - Call `sim.tick()` and increment `ticks` by `1`.

- **Settled Report**:
  - `nodes`: array of settled node objects with calculated `x`, `y`, `vx`, `vy`, and `radius`.
  - `links`: array of settled link objects whose `source` and `target` properties are resolved to their corresponding node objects.
  - `ticks`: total number of ticks executed.
  - `finalAlpha`: `sim.alpha()` after stepping finishes.
  - `converged`: `true` if `finalAlpha < alphaMin`, otherwise `false`.
