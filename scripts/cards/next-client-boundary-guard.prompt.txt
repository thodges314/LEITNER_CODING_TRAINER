Implement a Next.js React Server Component (RSC) to Client Component DTO serializer that validates and serializes props passed across the network boundary:

## Description

### Application Context
In Next.js App Router applications, Server Components fetch user and entity records from databases or backend APIs. When passing data from a Server Component to a Client Component (`'use client'`), props must cross the React Flight network serialization boundary:
- Sensitive server-only fields (such as `passwordHash` or secret tokens) must be stripped to prevent leaking credentials to client bundles.
- JavaScript `Date` instances are not directly JSON-serializable in standard props without formatting; they must be converted to ISO 8601 string representations.
- Missing required fields or invalid dates must be safely rejected.

```ts
interface ServerUserRecord {
  id: string;
  name: string;
  email: string;
  role: 'admin' | 'user' | 'guest';
  passwordHash: string;
  createdAt: Date;
  updatedAt: Date;
}

interface ClientUserDTO {
  id: string;
  name: string;
  email: string;
  role: 'admin' | 'user' | 'guest';
  createdAt: string;
  updatedAt: string;
}

interface SerializationResult {
  success: boolean;
  data?: ClientUserDTO;
  error?: string;
}
```

### `serializeUserForClient(user: unknown): SerializationResult`

Validates and serializes a server user record for client-side consumption:
- If `user` is not a non-null object, returns `{ success: false, error: 'Invalid user record' }`.
- If `id`, `name`, `email`, or `role` are missing or not non-empty strings, returns `{ success: false, error: 'Missing required user fields' }`.
- Validates `createdAt` and `updatedAt`:
  - Must be valid instances of `Date` (where `d instanceof Date` and `!isNaN(d.getTime())`).
  - If invalid or missing, returns `{ success: false, error: 'Invalid date fields' }`.
- Strips `passwordHash` from the output.
- Returns `{ success: true, data: { id, name, email, role, createdAt: user.createdAt.toISOString(), updatedAt: user.updatedAt.toISOString() } }`.
