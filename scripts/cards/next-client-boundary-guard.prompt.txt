Implement an async Next.js Server Component that fetches user data, safely strips sensitive server credentials, and passes client-safe props to a Client Component across the React Server Component (RSC) boundary:

## Description

### Application Context
In the Next.js App Router, Server Components fetch user and entity records from databases or backend services using internal models that contain sensitive server-only fields (such as password hashes, secret tokens, or internal flags).
When rendering a Client Component (`'use client'`) from a Server Component, all props passed across the network boundary are serialized into the client payload (React Flight format).
To prevent credential leaks, Server Components must safely project records by stripping sensitive fields before passing props to Client Components.
Furthermore, React Flight natively supports serializing `Date` objects across the boundary—manual ISO string conversions are unnecessary. If the requested entity does not exist, Next.js idiomatically terminates rendering by invoking `notFound()` from `next/navigation`.

```ts
interface ServerUserRecord {
  id: string;
  name: string;
  email: string;
  role: string;
  passwordHash: string;
  apiSecret: string;
  createdAt: Date;
}

type ClientSafeUser = Omit<ServerUserRecord, 'passwordHash' | 'apiSecret'>;

interface UserProfileContainerProps {
  userId: string;
  fetchUser: (id: string) => Promise<ServerUserRecord | null>;
}
```

### `UserProfileContainer({ userId, fetchUser }: UserProfileContainerProps): Promise<React.ReactElement>`

- **Awaits Async Data**:
  - Calls `await fetchUser(userId)` to retrieve the server record.
- **Not Found Handling**:
  - If `fetchUser` returns `null` or a falsy value, invokes `notFound()` from `next/navigation`.
- **Sensitive Field Stripping**:
  - Safely strips `passwordHash` and `apiSecret` using object rest/destructuring (`const { passwordHash, apiSecret, ...clientSafeUser } = user`).
  - Retains the authentic `Date` object on `createdAt`.
- **Render Output**:
  - Renders the pre-injected Client Component `<UserBadge user={clientSafeUser} />` inside a wrapper `<div data-testid="user-profile-boundary">`:
    ```tsx
    return (
      <div data-testid="user-profile-boundary">
        <UserBadge user={clientSafeUser} />
      </div>
    );
    ```
