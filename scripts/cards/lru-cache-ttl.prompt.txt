Implement a Least Recently Used (LRU) cache class with Time-To-Live (TTL) expiration in O(1) time:

### `new LRUCacheTTL<K = unknown, V = unknown>(capacity: number): LRUCacheTTL<K, V>`

- **`get(key)`**:
  - Returns the cached value for `key`.
  - Returns `-1` if `key` is missing or if its TTL has expired (expired entries are removed from the cache).
  - A successful `get` marks the entry as the most recently used.
- **`set(key, value, ttlMs = 0)`**:
  - Inserts or updates `key` with its `value` and optional expiration timestamp.
  - Marks the entry as the most recently used.
  - When inserting a new key beyond `capacity`, evicts the least recently used entry.
  - If `ttlMs` is omitted or `0`, the entry never expires.
